# 番茄向章节写法与篇幅弹性

## 目标

`serial` 默认以约 2500 个有效内容字符作为章节切换参考，约 2250–2850 字是常见落点，不是硬上限。写到这个区间且当前动作、选择、代价或余波出现自然落点，就结束本章；没有落点时可以略长，不能机械截断。用户要求连续多章时，完成本章后必须新建下一章标题，基于上一章真实后果重新规划并继续写，不能把多章正文合并成一章。每一章有自己的标题，标题只标这一章走到的那一截。章尾不把这件事收掉，停在正常往下走的地方：话还在说、人还在办、手还在动，下一章接着这一下写。不另加总结、钩子或「到此为止」。不刻意凑字。每章仍要有自己的入口和推进。场面若只剩对白，把这一截里的环境、衣着、动作和在意写开，不另开无关场面。`fanqie-short-story` 按已确认的全文与分节职责决定单节长度，可在不注水的前提下合理增加分节；单篇不分节时直接使用全文目标。平台统计口径可能不同；首次发布后以平台显示值校准。正文需要快，但不能把“快”误解为持续吵闹或机械反转。

## 先参考再写

禁止先写正文再补读参考。写前卡和章节细纲填完之前不得开写。

当场读取，不能凭聊天记忆代替：

1. [scene-craft.md](scene-craft.md) 的场面四行；
2. [fanqie-consistency.md](fanqie-consistency.md) 与 `canon/laws.md`、`canon/timeline.md`；
3. 上场角色 `cast/{id}/SKILL.md` 与 `state.json`；
4. `fanqie-short-story` 或番茄投稿：[fanqie-signing-quality.md](fanqie-signing-quality.md)、[fanqie-character-craft.md](fanqie-character-craft.md)；
5. 第一节或长篇前三章：[short-story-information-flow.md](short-story-information-flow.md)、[fanqie-new-book.md](fanqie-new-book.md)。

读完后才填下面的写前卡和 [章节细纲](chapter-outline.md)。卡或细纲填不出来就还没准备好。

## 写前卡片

动笔前用六行确定：

- 本章视角与当下欲望；
- 进入场景时已有的问题；
- 本章主要阻碍；
- 本章节拍级别：普通、`small` 或 `major`；
- 至少两项状态变化；
- 兑现的旧承诺或推进的线索；
- 本节事件阶段与局部交付；
- 结尾收束类型：动作完成、选择落地、代价显现、合理中断、认知改变或安静余波；若是短故事最后一节，写明最后一场动作怎样才算做完。

番茄出戏课的「目标 / 冲突 / 转折 / 钩子」对上写前卡；其中“钩子”可以由下一步行动、代价或自然收束承担，不要求额外补一句悬念。写战力、花钱、违禁前先对 [fanqie-consistency.md](fanqie-consistency.md) 与 `canon/laws.md`。

## 短故事分节写法

`fanqie-short-story` 的每节仍须有局部回报，但不把“短故事有结局”误读成“每节都要把一件事写完”。先标出本节事件线 ID 和阶段：`opening` 引爆问题，`middle` 推进并加压，`turn` 改变判断或代价，`closing` 完成事件级解决。前面阶段可以把未完成动作、选择后果或合理中断交给下一节；只有最后一节和标记为 `closing` 的分节才检查事件结案。

按 [章节细纲](chapter-outline.md) 列出本节通常 3–5 个场景拍。每拍写入口动作、目的、阻碍与反应、转折与代价、状态落点和离场条件。分节结尾只需落在当前动作、选择、代价或余波的自然位置，不强制总结、身份揭示、突然来人或断章钩子。对白主要交锋另填 [dialogue-craft.md](dialogue-craft.md)，把角色意图改写成受具体目的、回避和关系推动的台词。

如果删掉本章不会影响后续状态，本章尚无存在价值。写前先完成 [ensemble.md](ensemble.md) 的合同与裁定；写手不得发明角色没打算做的关键选择，也不得要求本章把当前弧写完。

## 长篇 3/5 章爽点节拍

本节只适用于 `serial`。短故事读取 [length-modes.md](length-modes.md)，用有限结构位置安排回报。

- 每一章都给读者至少一种实质回报，不让非节拍章沦为纯过渡。
- 第 3、6、9、12…章交付小爽点或小高潮：解决当前障碍、验证一次能力、拿到关键线索、赢得一次关系主动权，或完成一个短期目标。
- 第 5、10、15、20…章交付大爽点或大高潮：兑现阶段核心承诺，形成决定性胜负、重要真相、身份跃迁、关系定局或局势翻转，并改变后续目标或约束。
- 第 15、30…章同时命中两种节拍时，只设计一个更完整的 `major` 回报，由它吸收小爽点职责；不要在一章里生硬安排两场无关高潮。
- 爽点必须由此前选择、铺垫和代价挣得。旁人惊叹、数值上涨、突然送宝、反派降智和没有后果的打脸不算有效兑现。
- 连续两个小爽点或大爽点不得使用相同的“冲突—解法—回报”组合。

不同题材可交付不同回报：升级文兑现能力与地位，悬疑文兑现线索与推理结论，情感文兑现信任与关系选择，经营文兑现可见成果与新瓶颈，生存文兑现资源、安全区或规则认知。

## 节奏建议

- 前 300 字完成入口动作链：正在发生的处境、可辨认的关系/冲突、主角的主动选择，以及由选择产生的具体代价或下一问。前 100 字优先出现事件和压力，但不要求每 100 字固定一个反转。番茄开篇另按 [fanqie-new-book.md](fanqie-new-book.md)：第一屏要有功能看点，开篇花活必须进入主线。
- 中段至少发生一次因果升级：角色行动引出更难的新局面，而非作者凭空加事。
- 后段给予一种本节职责范围内的回报：答案、胜负、关系变化、资源变化、能力验证、阶段性线索、失败代价或情绪释放。跨节事件不提前交付整条事件线的结案。
- 结尾落在当前动作、选择、代价或余波的自然位置。下一步可以直接承接已发生的行动，不必每节都隐瞒信息、强行反转或加总结钩子。
- 段落适合移动端阅读，但不要把每句话都拆成一段。对白比例服从场景功能。连续独句成段超过一小场，按 `cadence-packaging` 处理，不要当成“网文节奏合格”。

## 正文落地

细纲回答「要发生什么」，正文把它演成角色此刻能感知的选择、动作、对白和物件。不要一个情节点写成一段、按序平推，也不要把「起因、发展、转折、高潮、结尾」写成五个自然段。细纲里重复出现的同一句要求，正文只演一次。状态变化要让读者看见中间态：先怎样、跟着怎样、最后成了什么。同一状态换十种说法，仍然只是一个台阶。

上章没做完的动作、没回答的问题或刚落地的代价，本章第一拍必须接着、拒绝，或写出不接的代价。不能用天气、起床或「回到住处」把场面重开。读完本章，读者要能说清发生了什么、谁做了选择、局面为什么已经不同。

小说让读者自己读懂，不靠一边发生一边交代。总结句是演完再盖章：动作已经看见了，又概括一遍，或把情绪和主题说成结论。交代句是边演边讲：来历、动机、规矩还没被人碰到，旁白先讲完。两样都删，改成此人此刻的动作、开口和对方的反应。人物嘴里说出来的价钱、时间和谁来做，是这场话本身，留着。赶路、时间跳过用一两句带过，那是省略，不是讲解。

长篇不要写成谁都能换进去的一段日子。短故事可以一场收完一件事。长篇这一场得用这本书里正在用的岗位、单据、地名和没还清的账；换一本书仍成立的「加班、房租、找亲戚借」，读起来就像短故事，也显得笼统。写在事情还没办成的地方，不要把整章收成回家后的几句汇报。这一场只让旧账更难还，或让一笔旧债露出新的边。

情绪和设定都只落一处，按这个顺序选，不叠成「动作 + 身体 + 比喻 + 心理」四重注释：

1. 前文已经让人看懂，就删掉补充，直接进入下一句。
2. 它改变下一步，就写因此说了什么、选了哪条路、付了什么代价。
3. 场内已有的合同、药、门、消息或工具变了，就写那个变化。不临时搬一只杯子来表演情绪。
4. 表情和心理按这一拍的需要写。读者看不见这个人、听不出他在意谁，就写脸上能看见的一点，或一句没说完的念头。动作、对白和物件已经把心情带出来了，就不要再补，那是画蛇添足。
5. 低强度过场可以一句直写，例如「他听烦了」。不必为躲开一个普通情绪词绕三十个字。

只落一处，是不把同一种心情写四遍，不是把人写成办事机器。全场只有单据、钟点和步骤，读者就只看见流程，看不见这个人在意谁。

表情、心理、衣着、环境都按情况取舍。该有的时候写：脸上一次一两处，不把眉、眼、嘴各写一遍；心理只留他没说出口、而且会改下一步的那半句，不写成完整的内心分析。不该有的时候不写。套话仍然不用：「眼中闪过」「嘴角勾起」「深吸一口气」「心中暗道」。需要脸时，换成这张脸上特有的一点，不换一套套话。「她很难过」「他这是愧疚」是交代。把名字咽回去、多嘱咐一句、同一张单先看人后看金额，已经够了就停。

一场不能只有对白。环境、衣着和动作跟话写在一起，读者才能跟着这个人把屋子想像出来。衣着留他会注意的一点，说话时手和脚步不停。不另起一段风景，也不把人写成服装目录。只剩两个人把条件说完，读起来就是僵的。

危险、能力和规矩不由旁白先下判词。让人物试一次并付出代价：伸手被弹回、看久了开始恍惚、退后绕开。旁白不先给答案。

金额、年限和距离只在改变当前选择时写出，并在同一段里换成读者已经认识的代价：上一章花掉的、现在缺的、刚见过的那个人花了多久。不把两笔账凑成刚好差一个零头。

本章新出现的名词从这场冲突里长出来。这一场用不上的第三个新规矩、新门派或新术语先不介绍。

安静可以是没人接话、回信没来、门外脚步被雨盖住。连续多拍只有打，检查是不是暴力疲劳；连续多拍只有等，检查是不是停滞。有意的追逐或有意的压迫可以保留。同一个情绪连写三段、回忆没有新角度、删掉后因果和关系都不变的流程，整段删掉。「然后回去睡了」如果没有留下改变后的状态，不算安静余波。

正文里不写「本章」「上一章」「细纲」「伏笔」「读者」这类工程词。需要承接时，改成角色能感到的那件事。角色真的在读一本书的某一章时除外。

一件事没写完也可以收在这一章，章尾不另收。不按字数补，也不按字数截断。场面又只剩对白时，回到这场已有的冲突把环境、衣着、动作和在意写开：被打断、对方作出主角没安排的反应、移动中发现已埋下的线索、动作引出连锁。不新开场面，不加回忆充字，也不为「显得自然」补一套办事流程。卡点只在人物本来要办成的事被卡住、并且卡住之后选择或代价变了时使用；删掉无损就删。

句子按真实的先后接上。一句里超过三个动作，用「就、才、又、便、先……才」分出先后，不写成逗号清单。少写「没做甲，也没做乙」。单独成行的短句只留给这一章最重的一拍。比喻用中文里现成的说法。标点跟着这句话在干什么：压迫和交代用句号；质问才用问号，不连着五句都问；爆发只留一个感叹号。犹豫和没说完，用停手、改口或句号切断，不用一串省略号充停顿。对白被打断的单个「——」可以留。叙述里用破折号把分句串成揭晓，按 [prose-naturalization.md](prose-naturalization.md) 改成逗号、句号或下一拍动作。

## 疏密、断段与在场的人

一章里的笔墨按权重分配，不按情节点平均：

- 爽点、打脸、关系翻脸、关键对决写具体的几下。密处禁止「一连七八下」「斗了半晌」「众人纷纷」这种把过程折成数字的概括。
- 赶路、交代、时间跳转用一两句带过。
- 三样物件、四拨人、五次出手：第一个写足，后面每个只留一个不重复的记号。被压缩的仍要有记号，不能直接消失。
- 重复使用的招式一句写效果。大招第一次可以写过程，以后不再把同一招详写一遍。

断段按镜头，不按字数，也不按「发生、感知、反应」拆开：

- 新动作、新物件、新信息、对白，另起一段。
- 同一镜头里的句子留在一段。连续极短段如果还是同一件事，合并。
- 段首点一次名字。段中用「他」或省掉主语。转折、换人、读者会搞混时再点名。连续多句都以同一个名字开头，又没有换场，就改掉。
- 全章最重的那一拍用最短的一段接住。要慢，用停顿，不靠把这一段写长。

在场的人先过镜头：

- 给镜头之前先回答这个人此刻在保什么、在算什么。答不上来就不给镜头。遮住名字仍认不出这句反应是谁的，就重写。
- 一场有台词的人控制在三四个。其余收成一个动作或一个目光。地位高的人话更少、更静。同立场的人并成一句，不必每人点名。
- 「厉害」「难得」「要命」由懂行或有利害的人在结果出来之前说。旁白事后宣布，或在场的人只「笑了笑、说了句什么」，都算没标价。
- 震惊要改变某人的计划或利益，不要全场一起「倒吸一口凉气」。有后续戏的人的反应才有用；路人齐声惊叹可以删。

角色自己感到的、文字写出来的、读者读到的，可以不是同一种情绪。她在撑，读者可以在等后面的账。读者还没认这个人之前，不要把对手写成可怜。只有加压、没有本章职责内的释放，读者会憋；只有释放、前面没有缺口，释放是平的。加压和释放落在这一拍里：先碰什么、冲着谁、哪半句没说完。不靠另加一段抒情。

悬念是读者看见两种都说得通的下一步，不是章尾必须再补一句钩子。短期、中期、远期期待不要在同一章全部兑现。旧麻烦被一次性解决光，后面就没有可写的压力。虚假提示必须在当场站得住，不能等反转时才宣布「其实刚才是假的」。

## 开篇前三章

新书前三章优先完成：展示主角最具体的困境；让核心卖点实际运行一次；给出可理解的近期目标；兑现至少一个小回报；留下能自然进入下一阶段的问题。不要用长篇世界史、人物简历或作者说明替代剧情。

### 长篇黄金三章入口

长篇开篇沿用短故事前 300 字的入口合同：读者应能说清“谁遇到了什么、主角做了什么、这个选择会失去什么、接下来等哪个具体答案”。第一章前 300 字按三个窗口落地，但不要求每窗固定字数或固定反转；300 字之后用三章把承诺变成可持续的连载发动机：

| 章节 | 必须完成的职责 | 结尾推动力 |
|---|---|---|
| 第 1 章 | 事件/压力正在发生；主角做出主动选择并付出具体代价；核心卖点至少运行一次 | 选择造成的行动后果或必须回答的近期问题 |
| 第 2 章 | 因果升级；明确近期目标、主要阻碍和一条有效新信息；主角再次选择而非被动等待 | 更高代价、不可逆承诺或下一步行动 |
| 第 3 章 | 交付一次真实的小回报或卖点验证；让关系、能力、资源、认知或局势发生可见变化 | 打开由前三章后果自然生成的连载目标，不凭空换主线 |

黄金三章是功能合同，不是字数合同。一件事可以拆进这三章，每章自有标题，章尾不把这件事收掉。若一章同时承载两个不能压缩的动作，拆章并写清新增职责，不能靠背景、重复对白或无后果反转填量。前三章完成后再接入长篇的 3/5 章爽点节拍。

番茄短故事还要在动笔前检查信息流入口：标题、前 300 字、主情绪发动机和试读节点必须指向同一个主承诺。按 [short-story-information-flow.md](short-story-information-flow.md) 与 [fanqie-new-book.md](fanqie-new-book.md) 做入口合同；需要精确截取时运行 `opening_audit.py`。不把固定反转频率、短段落数量或冲突词命中当成硬指标。看点密度只当枯燥信号，禁止为凑点注水。

## 人物与语言

- 写前读取 `canon/style-profile.md` 和最近两章，只提取叙事距离、句式节奏、对白机制、意象密度、禁用倾向五个锚点。
- 若风格档案含“个人声音证据”，优先执行有配对样本支持的规则。主要场景另确定视角人物会先注意/漏掉什么、各人当下利益、回避核心和压力反应；详细方法见 [prose-naturalization.md](prose-naturalization.md)。
- 用动作、选择、误判和带目的的对话呈现人物，不直接替读者总结所有情绪。
- 让不同人物拥有不同的注意点、句长、回避方式和利益立场，少靠口头禅区分。
- 检查重复解释、空泛感叹、四字词堆叠、万能微表情和连续比喻；只在它们损害本章效果时修改。
- 长短句随注意力和压力变化；避免整章同一节拍。
- 完成正文后先删一遍总结句和交代句：已被行动证明的意义说明、边演边讲的来历和动机、作者替人物下的情绪结论。再检查对白是否由人物利益驱动、结尾是否停在可见后果上。不要用随机句长、故意病句、方言或闲聊制造“人味”。
- 参考知名作者时按 [style-system.md](style-system.md) 使用手法转译卡，不复刻标志性措辞、固定句式或段落。

## 场面

意图收齐之后，按 [scene-craft.md](scene-craft.md) 把裁定写成可看见的空间、身体和动作过程。每个上场场景补四行：空间（出口、光线、距离、能伤人的东西）、身体锚、本拍「意图→过程→代价→反应」、视角会先抓住的感官。

- 环境只写视角此刻用得上的空间，不写导游词；景物必须能还手或改判断。
- 人物第一次出场给一个能再认的身体锚，之后只在关系、伤势或压力变化时再写。
- 动作禁止技能名加结果、禁止万能微表情；被否决的意图要写成试图失败。
- **打斗、追逐、破境抢关要大幅度加厚**：空间每回合改写，身体留伤，每一记走满意图→过程→代价→反应；对白让路。详见 [scene-craft.md](scene-craft.md)「打斗」。
- 主要场面自检：人站在哪、凭哪一点认出他、这一拍有没有代价和对方反应。打斗再问：有没有中间过程、空间或伤势有没有变。

## 配角与关系

- 写前读取 `state/cast-arcs.json`，优先让到达 `nextTurnWindow` 的核心配角进入能改变局势的场景。
- 配角参与关键场景时，至少让一人依据自己的目标作出主角没有安排的选择；选择应产生可追踪的收益、代价或关系变化。
- 配角弧光优先从其事业、信念、责任、身份、求生需求或既有关系中生长，不默认添加爱情。即使主角不在场，该角色的行动理由仍应成立。
- 关系可以是亲情、友情、师徒、同袍、竞争、债务、利益、恐惧或爱情。爱可以指向主角、反派或其他配角，但不等于被回应、被奖励、获赦免或自动洗白；双方仍按各自立场行动。
- 普通出场、赞叹主角、递送情报或重复既有态度不算弧光推进。只有选择及其后果能写入 `history`。
- 不为每个临时人物强造支线。`cameo` 完成场景功能即可，把篇幅留给真正影响主线的 `anchor` 和 `recurring`。

## 七项审查

1. **因果**：事件是否由人物行动、既有规则或明确外力导致？战力、金钱、规则、时间地点是否与法则库和时间线对得上？番茄投稿按 [fanqie-consistency.md](fanqie-consistency.md) 核对。
2. **人物**：主角与核心配角的关键选择是否符合各自欲望、恐惧、信息和成长阶段？配角是否拥有不依附主角的行动理由？情绪是旁白标签还是会改变下一步的身体反应？多人说话能否不用名字区分？番茄短故事按 [fanqie-character-craft.md](fanqie-character-craft.md) 核对。
3. **推进**：至少两项状态是否真实变化？
4. **回报**：本章或本节是否兑现了读者等待的某件事？铺垫有多高，释放就要有多可见：底牌亮出后，对手、局面或关系必须受到对应压制，不能亮完再被无代价反打。结果要能追溯到承诺对象的选择；高光不能被配角、机构或巧合无交换地拿走。本章不得提前用掉终局底牌。旧承诺要付一点利息，不能靠新地图把旧账岔开。高潮之后可以先留下一小段看得见的收益，不必立刻再加一场危机。若命中长篇 3/5 节拍或短故事结构锚点，回报级别是否达标并写入账本？
5. **新鲜度**：冲突、解法和钩子是否重复近期章节？
6. **语言**：是否符合风格档案的五个锚点，具体、易读、有角色声音，且没有无意的模板化表达？主要场面是否能回答「人站在哪、凭什么认出他、动作有没有过程与代价」？只剩对白和结果摘要时，先按 [scene-craft.md](scene-craft.md) 补场面。打斗场若仍能一句收胜负，必须加厚过程，不得用路人惊叹充数。
7. **签约质量**（番茄短故事默认；按番茄投稿的长篇同样执行）：本节有无空转或不推情节的大段？人物行为是否对得上意图？独特机制有没有真正运行？重要胜利有没有真实代价？最后一节的最后一场动作是否做完、有没有用主题金句替读者封口？对白是否在推进利益而不是轮流播报背景？第一节/前三章另查设定是否可预判、首屏有无看点、有无无效开篇花活。细则见 [fanqie-signing-quality.md](fanqie-signing-quality.md)、[fanqie-character-craft.md](fanqie-character-craft.md)、[fanqie-new-book.md](fanqie-new-book.md)。

先修因果、人物和推进，再修句子。每次写成或修改本章后，按 [webnovel-naturalness-review.md](webnovel-naturalness-review.md) 执行强制自然度审稿，再按 [review-system.md](review-system.md) 分离执行编辑审稿和目标读者模拟；番茄短故事同时执行签约质量检查与人物刻画四问。开篇另执行新书抓人四问。一次自动修订后仍有结构问题，报告并调整滚动章纲。

## 指标解释

`chapter_metrics.py` 提供有效字数、段落、对话比例、长段和重复段落信号。它不能判断文学质量：

- `lengthSignal` 只是节奏异常信号，不是停笔或续写的理由。一件事可以拆成多章，章尾不收这件事。不按字数补，也不按字数截断。
- 若新增场景只重复已有功能，不要复制一场来凑字数。下一件进下一章，并在章纲中写明职责。
- 对话少不一定有错；对白比例只用于发现与预期场景明显不符的情况。打斗、追逐场面对白偏少、过程偏长是合格信号；这类场面偏短时补动作过程，不补闲话，也不补金句段。
- 长段过多时按意义和动作切分，不按固定句数切碎。独句段过多时反向合并，不要继续切。
- 重复段落必须检查，避免误把刻意回环当错误。
