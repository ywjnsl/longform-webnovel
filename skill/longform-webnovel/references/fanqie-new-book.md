# 番茄新书抓住读者（写作与审稿）

把平台公开的拉新/新书课转成可观察检查。不保证爆款，也不把「直白、吸睛、快」写成所有题材的唯一正确风格。

本模块依据番茄小说网作家课堂 2026-03-23《爆款新书怎么写？吃透这四点，直接抓住读者！》。平台口径可能调整；作者提供更新课时以更新页为准，改本文件要点，不整段搬官方例文。

适用：新建项目、定名、`fanqie-short-story` 第一节、`serial` 前三章。连载中后段只借用「看点要密、不要枯燥」，不把开篇公式套到每一章。与 [fanqie-signing-quality.md](fanqie-signing-quality.md)、[fanqie-character-craft.md](fanqie-character-craft.md) 一起用：签约看合规与收口，人物看活人，本文件看新书能不能把人留住。

核心三点要求写成检查：**直白**（冷读者不用听前情提要）、**吸睛**（首屏就有功能看点）、**快节奏**（不相关描述不占开篇）。

## 方法一：设定新颖，不是换皮热梗

开书前问三句，写进故事合同或市场快照，不要等第一章写完再补：

1. 这个期待线在当前公开样本里是否已经很密？
2. 若有先例，微创新换的是哪一样可观察的东西（身份、场面、物件、第一次兑现方式）？
3. 读者读完入口后，能否预判后面每一拍怎么走？能预判则设定不够新。

合法：保留抽象期待线（信息差、掉马、身份反差），但第一次兑现必须是本书自己的。
非法：人物关系、核心危机、解决机制与样本或作者旧作同构，只换名字。按 [market-research.md](market-research.md)、[reference-adaptation.md](reference-adaptation.md) 与 `story_overlap.py` 处理。

旧瓶可以装酒，但至少要有一口别人没尝过的。热门题材不替代这一口。

作者明确热爱且不在最热赛道时，不把合同改去追榜；预制套路没有人物温度，走 [fanqie-character-craft.md](fanqie-character-craft.md)，不靠再堆梗补救。

## 方法二：开篇精铸，每句要有用

开篇每个字优先服务当前冲突。读者对未知作品没有耐心听前情提要。

| 检查 | 通过 | 失败 |
|---|---|---|
| 黄金三秒 | 第一句或第一屏已有异常、危机、反差或未完成动作 | 先简历、风景、世界观或多年回忆 |
| 三段内重点 | 前三段里至少有一处会改变下一步的具体信息 | 三行之后仍只有气氛或态度 |
| 300 字进主题 | 与 [short-story-information-flow.md](short-story-information-flow.md) 同一条因果链 | 300 字仍在介绍背景 |
| 创新有效 | 开篇花活进入主线：删掉后主线或缺因果 | 金句、日历、排比很新，但与当日命运无关 |

背景、起末、设定用一句因果或对白带过，插在动作里。故事是重心。

开篇剧情自问：勾不勾人、有没有悬念、有没有情绪拉扯、快不快。读者模拟必须指出「哪里枯燥」；作者或冷读者说某句平淡，优先删或改，不保留「不影响阅读」的过渡句。

## 方法三：看点要密，但不是配额

看点可以是一句有效的梗、一次炸裂选择、一次反套路行动、一次情绪拉扯、一句会改距离的对白。阅读过程应轻松、可沉浸，不像在做功课。

公开课给过密度口诀。本 skill **只当枯燥信号，不当字数配额**：

| 信号 | 合法用法 | 非法用法 |
|---|---|---|
| 约 300 字一处小看点 | 连续一大段注意力不变时，检查是否空转 | 为凑点新开闲聊、金句墙、第二现场 |
| 约 500 字一处小钩 | 未完成动作、未答的具体问题、代价将落 | 每 500 字硬塞一句悬念旁白 |
| 一章一个完整场面 + 结尾推动力 | 章末有必须采取的行动、代价或新判断 | 把长篇约 2500 字信号改成 1000–1500 硬配额；或一章堆两个不能压缩的高潮 |

短章合法。看点必须改状态、距离或下一问。删掉后主线不变的「趣味」是 `padding-expansion` 或 `cadence-packaging`。

长篇前三章先让核心卖点运行一次并兑现小回报；其后仍走 3/5 章节拍，不把开篇密度套到第 20 章。

## 方法四：读者视角打磨，不写预制菜

写拍之前先预设读者反应：会不会想往下翻、会不会觉得平、这句对白有没有用。读者模拟的 `drop-risk` / `stop` 在开篇按高优先级处理。

禁止：

- 用作者自己都觉得枯燥的热门公式覆盖已确认合同；
- 把「爆款四点」当成可以拼装的预制结构，人物没有欲望和代价；
- 用市场流行元素直接覆盖作者已确认的热爱点。是否转向是重大决策。

市场会变。需要定位时读 [market-research.md](market-research.md)，只写当前样本能支持的结论，不把某一周的拉新文写法写成永久定律。

## 写节与审稿必答

开篇或第一节的 `editor.diagnosis` 用一两句覆盖：

1. 设定的微创新写在哪？读者是否还能预判后文节拍？
2. 第一屏有没有功能看点？前 300 字是否进主题？有没有无效开篇花活？
3. 本节有没有连续大段零看点？补点时有没有注水？
4. 冷读者指出的枯燥句改了没有？

`moments` 必须引用劝退原句，不能只写「开篇不够爆」。
