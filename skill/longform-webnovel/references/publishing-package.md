# 书名与封面提示词

## 正文前闸门

第一章正文之前，必须向作者展示并确认：候选书名、推荐理由、公开检索结果、封面主提示词、负面提示词，以及书名排版与字体说明。确认后写入 `canon/publishing-package.md`。不得先写正文，再补一个与内容无关的包装。

已有连载迁移时保留原书名和既有封面。只有作者要求改名或换封面时才重新走确认流程。

## 避免烂大街书名

先生成 8–12 个候选，至少覆盖三种命名机制：

- **独特物件或规则**：抓住只属于本书的物件、职业、制度或异常规则。
- **人物与矛盾**：把主角身份和不可兼得的目标放在同一标题中。
- **悬念或反差**：标题本身形成一个读者想追问的问题，但不泄露最终谜底。

淘汰只有题材词和情绪词的标题，例如仅用“重生、逆袭、最强、战神、末世、修仙”等高频词拼接。长标题也必须提供本书独有信息，不能只是“开局 + 金手指 + 无敌结果”的句式填空。

候选进入终选前执行：

```bash
python3 <skill-dir>/scripts/publishing_package.py --check-title <候选书名>
```

本地检查只能发现明显公式。再对前 3 名做公开精确检索：至少覆盖通用搜索引擎和目标网文平台；搜索完整标题、去标点标题和最有辨识度的 4–8 字短语。记录检查日期、平台、同名/近似结果和判断。不要声称绝对唯一，只说明检索范围内未发现高风险撞名。

评价候选时看四项：与核心卖点的绑定度、口头传播、封面可读性、精确检索区分度。最终定名属于开书重大决策，由作者确认。

番茄短故事另做一次信息流检查：标题应让读者一眼识别至少一个人物/关系或类型信号，并暗示一个具体事件和反常结果、代价或问题。可以使用文学化短名，但必须在简介和首屏补足“谁遇到了什么”；不要为了追求接近 30 字牺牲清楚度。详细的标题与开头合同见 [short-story-information-flow.md](short-story-information-flow.md)。

## 封面提示词

先读取 [cover-typography.md](cover-typography.md)。封面不能只有插画描述和一句泛化字体建议；图像主体与书名视觉都属于入口信息，必须一起设计。

提示词必须从已确认的故事合同、题材和语言风格推导，至少写清：

- 封面比例和用途。番茄小说签约作品当前公开要求为 `600×800` 像素、`3:4` 竖版，文件不超过 `5MB`；若目标平台规则变化，以最新帮助中心为准；
- 唯一视觉主体及其可见行动，不只写“一个帅气主角”；
- 能展示核心卖点的环境或关键物件；
- 构图层级、视线方向和书名安全区；
- 光线、颜色关系、材质和情绪温度；
- 与题材相符的写实度或插画表现方式；
- 不出现哪些错误元素的负面提示。

番茄成品封面还必须包含准确书名和作者笔名，字迹清晰、完整、无缺失或遮挡；不得包含外站 Logo、二维码、网址或水印。作者笔名必须使用后台真实笔名，不让图像模型自行编造。

封面包装还必须单独说明书名如何落版。先提出 3 个结构差异明显、与题材相符的方向，例如“竖排飞白榜书”“横向立体块字”“斜切速度标题”，不能只是同一版式换颜色；推荐 1 个后至少写清：

- 书名准确文字、断行方式和最多行数；
- 书名位置、对齐方式、占画面宽度比例和四边安全边距；
- 中文字形骨架与笔画性格，例如瘦长竖势、宽扁重心、飞白枯笔、方头切角、外扩横画；字体家族只作为后期排版参考，不能只写“古风字体”或“书法、大气”；
- 字号层级、字色、材质、内外描边、投影方向、立体厚度、局部高光等可执行字效；
- 文字层与人物、道具、光源的前后关系，允许局部压图时要指出具体压住哪里、不得遮挡哪里；
- 作者名的位置、字体、字号和与书名/主体的避让关系。

按目标工具交付三段可直接使用的内容：

1. **一次成图提示词**：当用户明确使用番茄或其他能生成封面文字的平台工具时，必须包含准确书名、固定断行、阅读顺序和完整字效，不得仍然只给“无文字底图”。
2. **纯底图提示词**：保留与推荐字效匹配的标题负空间，供后期排版使用。
3. **标题区域重绘提示词**：只修改指定标题区域，保留人物和背景，逐字列出准确标题并重申禁止增字、漏字、错字、拼音和英文替代。

不在提示词里要求模仿具体在世艺术家，也不使用受保护角色。生产质量优先时仍推荐“底图与文字分层”，但不能用“模型可能乱码”作为不给平台直生文字提示词的理由。作者笔名未知时使用明确占位符，不自行编造。

交付前做缩略图审查：把封面按约 `120×160` 像素观看，主标题仍须在 1 秒内辨认，字形不能与高光或人物五官粘连。书名超过 12 个汉字时优先拆出主标题与小号副题，不把全部文字塞成同字号三行。

避免“电影感、史诗感、细节丰富、8K”等空词堆叠。每个视觉元素都应回答：它如何让读者一眼看出这本书独有的冲突？

平台依据（查阅日期：2026-09-02）：[番茄作者帮助中心《签约作品封面、简介、主角名基础信息修改》](https://fanqienovel.com/writer/zone/article/7257101363962708023)。

## 保存包装

把定位、封面主提示词、负面提示词和公开检索记录分别写入 UTF-8 临时文件，然后运行：

```bash
python3 <skill-dir>/scripts/publishing_package.py \
  --project <项目目录> \
  --title <确认书名> \
  --positioning-file <定位.txt> \
  --cover-prompt-file <封面提示词.txt> \
  --title-layout-file <书名排版与字体.txt> \
  --negative-prompt-file <负面提示词.txt> \
  --research-notes-file <检索记录.txt>
```

`--title-layout-file` 可省略；此时用 `--cover-style` 选择 `editorial-impact`、`classical-calligraphy`、`cinematic-3d`、`action-display`、`emotional-handwritten` 或 `mystery-file`。新书仍应先按题材给出 3 个方案并把推荐方案写入专属说明，不应长期依赖默认值。脚本会备份并同步 `project.json` 与 `canon/publishing-package.md`。已有正文后改名必须先记录重大决策，再加 `--confirmed`。
