# 对白执行与人物声线

正文或审读发现对白同声、信息难懂、口气被旁白反复翻译时再读。下面是处理具体问题的方法，不是每句对白的验收配额；同一场可以在日常、交锋和回避之间自然变化。

正文对白用中文双引号“”，话里套话用‘’。沿用作者确认的排版选择时以作者要求为准。

## 先判断有没有问题

顺读必要前后文，判断这句话是否符合此人的经历、知情范围、关系和当下情绪。普通应答、共享词汇和直接说出感受都可以成立，不因单句换人也能说就重写。真正的问题是：成段交换说话人仍不影响任何利益与关系，或者人物只在代作者运送信息。

允许长句、短句、语气助词、重复、改口和沉默。作者认可的口头习惯可以保留，不靠机械分配一种句长或一个口头禅来区分人物。

## 按问题选择方法

| 具体问题 | 可尝试的调整 | 保留边界 |
| --- | --- | --- |
| 日常对白只剩步骤，没有相处方式 | 把称呼、叮嘱、礼貌或没说圆的话放回人物嘴里 | 不给每句均匀补语气词；安慰和闲聊无需推进剧情 |
| 交锋听不出各自要什么 | 写清此人的要求、回避、旧账或下一步后果 | 有人失语、只说“你怎么能这样”也可能是有效反应，不强迫人人善辩 |
| 真情绪被说得过满 | 可以答半句、问旁边的事、说反话或保持沉默 | 直接表白、痛哭、争吵也可成立，不把含蓄当唯一自然写法 |
| 双方都知道的背景被完整讲一遍 | 删重复说明，或让信息落到此刻的分歧 | 核对、审问、教学和刻意重复可有必要功能 |
| 台词后总跟一段态度说明 | 比较台词与旁白是否表达同一层意思，只保留有新功能的部分 | 心理、误解、幽默和已确认的评论型旁白可以增加新意 |
| 动作夹在每句台词之间，节拍单调 | 合并同一瞬间，让人物连续说话，保留必要站位或反应 | 不按动作数量删除；迟疑、照料和生活细节可承担关系温度 |
| 每个人都像冷静的辩手 | 回查不同利益、注意、恐惧与知情范围，让其影响回应 | 不额外制造误解或失败来凑差异 |

## 场景例子如何使用

日常叮嘱可以把话说完整：“汤还在锅里呢，火我关了。你回来热一下，别开太大啊。”若旁白只是再说她怕他饿着，可以省去；若旁白揭示她有意隐瞒另一层担心，则可能有新功能。

交涉可以通过期限或归属产生压力：“过了今晚，这单就不算你的了。”这适合正在谈条件的场景，不能成为所有角色的默认句型。战斗、亲密关系、喜剧和抒情各自有成立的语言方式。

这些例子仅说明选择，不是要复刻的台词或节奏。书里没有类似场景时直接略过。

## 修订与核验

先指出具体原句与阅读问题，再在原范围内提出候选。比较问题是否缓解、人物口气与情绪是否保留；两种写法只是不同，就保留作者认可的原文。
