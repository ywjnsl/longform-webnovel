# 对白执行与人物声线

对白不是把剧情说明换成引号。每句台词都应来自此刻的人、关系和压力；人物可以说错、说半句、绕开、改口或沉默，但读者仍要能从上下文拼出因果。

## 写前对白卡

主要交锋开始前，为每个说话者写五项：

- **想拿到什么**：一句话、一个动作、一个承诺、一个让步或一段时间；
- **不愿暴露什么**：事实、恐惧、责任、依赖或真实目的；
- **默认策略**：追问、试探、压价、讨好、转移、装傻、讲规矩、先攻击或先沉默；
- **关系语域**：称呼、礼貌距离、能否直呼其名、哪些词会改变关系；
- **压力下的破绽**：说得更短、更绕、更快，突然改称呼，重复一个词，或者直接做不说。

写手只把这些当作选择依据，不把它们机械变成口头禅。人物的声音首先来自他想拿什么、怕承认什么和知道什么。

## 一轮对白怎么推进

一轮交锋至少完成以下两项：交换有效信息、改变立场、迫使选择、暴露关系、制造误判、改变行动距离或付出代价。可以按“开口目的 → 对方偏移/拒绝 → 说话者调整 → 新条件”推进；不要求每轮都有漂亮反驳，也不要求双方把观点说完整。

每个角色连续说两句以上时，检查第二句是否因为对方的具体反应而改变。若只是把同一观点解释得更完整，删掉、改成动作，或让对方打断。不要让所有角色轮流完成“陈述事实—精准反驳—总结结论”。

## 防止固定台词

- 删除脱离上下文也成立的万能句：标准安慰、标准威胁、标准反问、标准总结；换成此人此刻要达成的具体动作或要求。
- 不让人物即时说出作者事后才知道的最佳表达。允许答非所问、误解、漏说和过几拍才补上，但遗漏必须影响判断或行动。
- 让称呼、礼貌、句子长度和信息分配随关系与压力变化；不要只给每人分配一种句长或一个口头禅。
- 对白可以重叠、被打断、说到一半停住，也可以完全没有对白；这些变化必须来自利益、信息差或情绪，不按段落配额插入。
- 同一场里保留少量重复词或固定表达只有在它暴露习惯、阶层、职业或压力反应时才有用；反复出现但不改变关系的口头禅应删除。

## 对白验收

逐句抽查：

1. 这句话是此人现在愿意说、敢说且认为有用的吗？
2. 换另一个角色说，是否也同样成立？若成立，重写利益、信息或关系位置。
3. 对方不回应这句话，场面是否仍然向前？若完全不变，这是作者说明，不是对白。
4. 这一轮结束后，谁的选择、判断、距离、资源或代价发生了变化？没有变化就删或并入动作。

自然对白不等于故意口语化、加语气词、制造病句或堆网络梗。清楚、完整、克制的句子只要有角色立场，也可以成立。
