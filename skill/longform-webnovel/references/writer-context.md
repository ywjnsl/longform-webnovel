# 正文写作的精简上下文

筹备完成后用本文进入正文。试写只使用已有材料，不先补齐正式项目。正式入库的筹备、编辑和提交按 [task-workflows.md](task-workflows.md) 执行。

## 筹备向写手交什么

沿用已有合同、裁定与 `precard.md`，只交当前事件需要的依据，不另建卡片或JSON字段：

- **正在发生的事。** 前文停在哪里、接下来仍在做什么、怎样才算这件事完结；长篇沿用四句前卡，跨章未完就继续。
- **相关正文。** 最近1—2章中需要承接的内容，尤其保留接续场面的原文；更早的关系转折或承诺确实影响当前选择时再回查。摘要不足以判断声音或相处方式时读对应原段。
- **人物与事实。** 当前视角、各人的诉求与已裁定关键意图、知情边界，以及会影响这次行动的时间、空间、伤势、资源和世界规则。必要的旁白权限一并保留；其他角色的隐情不因此自动变成视角人物已知。
- **声音依据。** 已确认风格及适用于当前人物或场面的少量短原段，说明值得保留的口气或对白习惯。作者确认样本优先；没有时用既有有效正文或暂定风格，不编造“作者样本”，也不逐句复刻。

筹备可读取完整设定和机制参考，但交给写手的是具体条件。例如将“奖励与退出权”落实为“他不想接受任命，对方仍扣着放行文书”，无需再要求正文展示退出权、成长和政治隐喻。没有相关情况时不调用该机制。

动笔时

从前文停住的地方接着写，按人物的注意、处境和回应安排笔墨。对方刚说的话可以改变下一句，人物也可以暂不回应。心理、幽默、必要交代、连续对白和安静停留都可保留，详略沿用这部作品的声音。

写人，不写单据和流程。合同、回单、称重单、排班表或窗口手续只能作为一两句背景或证据，不能当成场景的主角。人心里有气、有委屈、有护短、有嘴硬、有心动，就直接写出来，或者放进完整的话里，不要为了避开“解释”把正文削成「看了一眼、签了字、把门锁上」的短句电报。甜宠的主戏是偏爱、拉扯、心软和靠近；现实文的主戏是人怎么被逼急、怎么当面让人下不来台。结尾要落在人和关系的真实变化上，不能停在锁门、刷网银、放工牌或关指示灯。

**第一遍就按实时场面把字数写透，严禁“先写一篇四千字梗概，再回头往中间插段扩写”**：
- **分 3–4 块顺序接续直写，不一口气奔结局**：哪怕最终交付的是单个短故事 `.txt` 文件，也严禁在一次输出里从开篇一口气写到大结局（单次输出必会压缩中段、用概括代替场面，只写出四千字大纲）。必须把全篇拆成 **3–4 次连续写作（每次写透眼前的 1–2 个场面，约 2500–3500 字）**：第一块只管把开局冲突和第一次卡壳写透，停在事情还没办完的地方；下一块再接着往下写，直到最后一块才写结局。这样第一遍就能自然长够一万字，根本不需要事后回头往中间塞肉。
- **把“他说/她说”的摘要转述还原成实时双引号过招**：初稿字数不够，十有八九是因为把当面吵架写成了会议纪要（如“陆衡揉着眉心说公司要上线……老太太接过去嘀咕……陈姐打来电话说……”）。只要两个人在场有分歧，必须拉开架势用双引号 `“”` 一句顶一句实时交锋（全篇直接对白占比通常在 `30%–55%`）：对方怎么拿话堵人、这边怎么抓眼前的毛病回嘴、旁边人怎么插话帮腔或打岔，当场演出来，只把无关紧要的寒暄留给转述。
- **一件事别一次顺滑办成，靠“中途出岔子”长篇幅**：不要排“拒劝 → 喂奶 → 称重 → 辞职”四个顺风顺水的过场（一件事两百字就办完，写完肯定不够字数）。让每件正事在办到一半时**出一个具体的岔子**（比如答应夜里补瓶，结果半夜发现奶粉结块或水温烫手、孩子呛奶把全家哭醒；去社区称重，出门找不到出生证，到了诊室婆婆又因为偷偷喂过米汤跟护士顶起来）。靠解决眼前的岔子把场面撑满，严禁事后靠塞「职业流程分解 + 一段旧事补叙 + 一句收题金句」凑字数。

动笔时不用揣着禁用词表自我审查（单句的“不是…是…”、偶尔的职业动作或短句抢白只要合乎人物口气都能写），只守住四条让场面像活人的底线：
1. **首尾有人，转场跳切**：第一段直接从活人开口、发难或正在交手的动作切入，不拍环境空镜，也不要在前五百字按清单把所有设定、拒绝、代价和倒计时像填表一样一次塞满；换时间地点直接切进下一场有人的事，不写超过百字的单人赶路、干活或发呆哑剧；结尾停在人话或当场反应上，不拍“门关了、灯灭了、东西留在原地”的静物淡出。
2. **话顺私心，题眼不复读**：吵架、交涉、训话只算眼前的具体实账（几点、多少钱、谁受累），不要让不同身份的人全员围着“钟、窗、门、灯”念格言，也不要把标题里的核心比喻（如“买嘴、传话、借台阶”）从开篇、中段、高潮一路换人复读到结尾。一个比喻在冲突当场刺痛一次就够了，后面直接写新的阻碍，不用“你的卡用来A，我的卡用来B”这种工整对子收题。
3. **职业动作只写卡壳处，不演慢镜头**：人物干活（修车、月子护理、做饭、缝补）只在出错、烫手、被打断或改变对方态度时带一笔，不要一句台词配一套精细的工种分解动作，也不要在段尾补“东西修好了，可那股力道还留在那儿”的抒情余味，或由旁白跳出来喊“心里一下子通透了”。
4. **句随呼吸，直接开口，别把交锋焖成“他说/她说”的匀速长句墙**：人急了、噎人、打岔时就用直接引号三五个字顶回去，算细账、倒苦水、心里犯嘀咕时再顺着口气连成大长句。只把顺手带过的招呼（如“顺手接过包让放后座”）融进间接转述，**核心交锋、顶嘴和讨价还价必须用双引号直接说出来**，严禁为了躲“乒乓球对白”或“短句电报”把整场戏写成“陆衡说……何棠说……苏晚宁说……”的间接转述长句墙（一旦连最短的 25% 句子都超过十七八个字、没有短促抢白，就会变成死气沉沉的规训体）。成簇的句法毛病留给写完后的编辑扫描局部打散，写的时候顺着人物当下的气口往下推。

正文对白用中文双引号“”，话里套话用‘’。沿用人物既有口气，允许日常闲聊、直接表达、回避和沉默；同一场也可以随关系和压力换说法。人物声音来自他的经历、注意和利益，不靠统一短句或分配口头禅。

动作、心理、环境与叙述评论按本作品的声音取舍。幽默、抒情、停顿和暂不推动行动的细节可以成立；必要说明也可以由旁白直接完成。只有信息重复、知情越界、人物失真或阅读难懂等具体问题成立时才改，不先替每句话分配功能。

开篇让读者获得与故事承诺相符的阅读理由，可以来自关系、气氛、异常、处境或叙述声音；不强制物件出场、结果式书名或固定句数。番茄入口方法由筹备按目标读者选用，写手只接收本次选定的具体目标。

规则博弈、证据交涉或对白同声确有问题时，编辑再按相应参考诊断。这些诊断只由编辑按具体问题选用，写手不预先补答诊断问题，也不照参考例句复刻节奏。

角色的理由可以没说全，他也可能没想清楚自己的感受。关系暂不升级，信念暂不改变，已经发生的选择仍可以推进事情。读者能理解当前处境即可，不必再由旁白替人物总结意义；同时保留理解新条件所需的说明。

`serial`、`novella` 的写作单位是正在发生的事件，章是文本切片。不要给写手下“写一章约2500字”的任务，也不预先分配本章要完成的剧情、拍数、章尾或标题。实际执行是：连续写这件事并保存草稿 → 用 `chapter_cut.py <草稿文件> --target 2500` 实测并定位切点 → `ready` 时按该边界切出原文 → 该片审稿提交后，从断处继续同一件事。无需等对话结束、动作完成、局势改变或阶段结案再切；不为落在字数附近加快、压缩或延长事件。

切点后已经写出的正文原样留给下一片；前片不补过渡和总结，后片不重述、不重新开场。标题按实际切出的内容再定；合同、阶段与回报也按该片实际发生的内容确认。同一未完事件跨章沿用前卡、意图与裁定，只更新真实接续；新事实影响人物选择或行动合法性时再补充筹备。归档按 [ensemble.md](ensemble.md) 复制有效快照，不重新生成一套人物打算。审稿与状态仍逐章提交，但这道事务边界不决定剧情走到哪里。

切片后由项目维护按 [operations.md](operations.md) 保存前片与尾稿。恢复时先读最终已提交章的结尾及项目内工作尾稿，再从工作尾稿末尾续写；前章审稿改变了动作或事实时，只修正受影响的接续，原始尾稿留档，不覆盖恢复快照。尾稿尚未成为正式章节，其中内容不能提前当作正史。

例如，同一件事连续展开约6300字，可以切成约2500、2500和1300字；前两处只是断开文本，最后一片才走到该事件的结束。不要先设计三个各自完整、各长约2500字的小故事。作者只要一章时，到首次切点结束本次交付，保留事件未完；连续多章时从断处往下写。`serial` 贯穿线卷末落地后停止，不自动开新卷；短故事沿用已确认的分节职责与全文结局，不套用这套切片办法。

写法确有困难时才补读对应参考的小节：对白用 [dialogue-craft.md](dialogue-craft.md)，空间或关键过程用 [scene-craft.md](scene-craft.md)，篇幅与疏密用 [chapter-craft.md](chapter-craft.md)。已有依据足够时直接写，不逐段轮流实现教程中的功能。

## 写完交回编辑

交出正文后，试写和局部候选按轻流程检查；正式入库时再按完整流程检查、定向改稿和更新状态。已经切出的章经语言修改后稍短，按改前基线检查有效叙事是否保留，不追加剧情或挪用下一片补到阈值。评分表、机制清单与自然度问题簇由编辑使用，不能当作正文中尚待补齐的表现项目。

修订者收到具体问题原段、必要前后文、要解决的读者困惑及允许范围。对照候选与原稿选择读感更有效的一版；改后人物更同声、解释更多或情绪变薄时恢复相应原段。问题不存在就保留原文，不为证明“做过自然化”整章重写。
