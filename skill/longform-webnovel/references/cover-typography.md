# 番茄封面书名字效

封面书名不是插画上的说明文字，而是缩略图里最先被识别的视觉主体之一。先从题材承诺、标题长度、人物构图和情绪强度中选择视觉语法，再写生成提示词。不要把“书法、大气”“艺术字”“高级感”当成可执行设计。

## 必须拆解的八个参数

每个候选方向都要明确以下参数，缺一项时补齐后再交付：

1. **阅读结构**：准确书名、固定断行、横排或竖排、从左到右还是从上到下；禁止模型改写标题。
2. **标题块位置**：上部、中腰、下三分之一或沿侧边；给出约占画面宽高的比例和四边安全距离。
3. **字形骨架**：瘦长或宽扁、重心高低、字面大小、横竖对比、外扩或内收、端点方圆。
4. **笔画性格**：飞白枯笔、粗粝干刷、碑刻顿挫、几何切角、速度拖尾、柔韧手写等；只选与题材一致的一至两种。
5. **材质**：哑光墨、旧纸渗墨、金箔、铜锈、烤漆、金属、石刻、霓虹玻璃等；说明高光与磨损程度。
6. **边缘系统**：内描边、外描边、包边颜色与相对厚度；复杂背景至少使用两级明暗分离。
7. **空间效果**：平面、浅浮雕、斜向挤出、长投影或透视收束；说明方向和深度，不能只写“立体”。
8. **图文关系**：标题在人像前还是后、允许压住肩膀或衣角的比例、禁止遮挡眼睛嘴巴和核心道具；背景光应服务文字轮廓。

## 五种可迁移方向

这些是视觉语法，不是固定模板。每次应结合故事专属物件、色彩和构图变化。

### 竖排飞白榜书

适合古言权谋、宅斗、历史悬疑和强命运感。主标题纵向贯穿中部或左中部，2–3 列错落；字形瘦长、重心略高，行楷或榜书骨架，起收笔有锋，粗细反差大，保留可见飞白与枯笔。使用旧宣纸暖白、哑光金箔或朱砂色，配细暗红/深褐外描边和很浅的纸面投影。可加一枚小号朱文印章承载类型短语，但印章不能伪装作者名。

### 横向立体块字

适合职场逆袭、官场、公考、商战、都市升级。标题放在上半部或中腰，1–2 行横排，宽扁几何黑体骨架，笔画粗、字腔紧、方头切角；正面用亮橙、象牙白或金黄，内侧有窄高光，外层先深红包边再加黑蓝细描边，向右下挤出短厚立体侧面和硬投影。副标题缩小到主标题的 28%–38%，放在主标题下方独立横条内，不与主标题抢层级。

### 斜切速度标题

适合刑侦、公安、都市动作、复仇爽文。主标题占下三分之一，整体向右上倾斜 5–10 度，超粗紧缩黑体，端点用刀锋切角，部分横画外伸形成速度感。正面使用暖白到橙红的硬渐变，白色内高光、深褐粗外描边、黑色短投影；允许标题压住人物肩部或制服下缘 5%–10%，不得遮挡脸和徽章。可用一条锐利红色速度线穿过字腰，但不让线条破坏字形识别。

### 情感手写主标

适合现实情感、婚姻家庭、青春虐恋。主标题放在留白较多的一侧，1–3 行错落，使用有人工停顿感的粗手写骨架，字面大小略有变化但基线稳定；不做儿童涂鸦。哑光暖白或低饱和红色笔触，配单层深色描边和柔和短阴影。用一处故事专属物件替代装饰性笔划，例如缴费单折痕、录音波形或断线，但不能直接复用市场样本的独特物件。

### 冷峻悬疑题签

适合犯罪悬疑、规则怪谈、灵异惊悚。标题置于上部窄区或沿侧边纵排，窄长宋黑混合骨架，横细竖重，字距紧，局部像被档案裁刀截断。使用骨白或警示红，外加深黑细描边，不做大面积霓虹。编号、日期或档案章只能作为小号辅助信息，不能喧宾夺主，也不能伪造真实机构标识。

## 三方案必须真正不同

每次给 3 个方向时，至少有两项结构差异：横/竖排、标题所在区域、字形骨架、空间效果、图文前后关系。仅把金色换成红色、宋体换成黑体不算不同方案。

推荐时说明它如何传达本书独有冲突，而不是只说“更吸睛”。例如：“竖排标题像一道陪葬诏令压在棺盖上，能把女主扣下名单的行动变成第一眼冲突。”

## 一次成图提示词结构

按以下顺序写成一段自然语言，不输出空泛关键词串：

```text
用途与比例；唯一人物/物件及动作；场景与光源；主体位置和标题负空间；
准确书名与固定断行；阅读顺序；字形骨架；笔画性格；材质；描边层；
投影或立体方向；标题占比；标题与人物/道具的前后关系；作者名占位；
缩略图可读性；禁止错字、增字、漏字、英文替代和无关文案。
```

标题较长时，在提示词中逐行引用，例如：

```text
准确生成中文书名，仅两行：第一行“公考逆袭”，第二行“从面试开始一路攀登”。
不得交换行序，不得添加书名号，不得把“考”写成相似字。
```

## 纯底图与区域重绘

纯底图提示词仍须指定未来标题块的位置、亮度和纹理复杂度。例如“画面左中部保留约 32% 宽、60% 高的暗红低纹理区，供三列竖排金白书法标题使用”，不能只写“留白”。

标题区域重绘提示词必须写明：

- 只修改哪个矩形区域，人物、背景、道具和光线保持不变；
- 准确标题与逐行文本；
- 推荐方向的八个参数；
- 禁止新增副标题、营销语、Logo、二维码、水印、拼音和英文；
- 汉字仍错误时停止反复整图，改用无字底图后期排版。

## 负面提示词

除项目专属禁项外，至少排除：错别字、漏字、重复字、乱码、拼音或英文替代、阅读顺序错误、标题被裁切、字与人脸粘连、细字低对比、塑料发光字、廉价金色浮雕、过厚描边糊成一团、同层级副标题、无关宣传语、外站 Logo、二维码、网址、水印、真实机构徽标、受保护角色、模仿具体在世艺术家。
