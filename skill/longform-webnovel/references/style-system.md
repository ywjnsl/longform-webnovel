# 语言风格选择与手法转译

## 选择原则

语言风格服务故事承诺，不代替剧情推进。新书在故事合同阶段选择一个主风格；确有必要时再加一个辅风格。主风格决定可读性、叙事距离和句式底盘，辅风格只调节局部质感。

| 标识 | 名称 | 适合的核心体验 |
|---|---|---|
| `fanqie-clean` | 清晰推进 | 通用番茄节奏、升级、经营、都市成长 |
| `suspense-tight` | 冷峻悬疑 | 推理、规则怪谈、秘密调查 |
| `warm-grounded` | 温暖烟火 | 年代、家庭、日常经营、群像 |
| `witty-dialogue` | 机锋轻喜 | 轻喜剧、欢喜冤家、职场或团队互动 |
| `lyrical-restrained` | 克制抒情 | 情感、成长、带文学质感的幻想 |
| `historical-plain` | 古意白描 | 历史、古言、权谋、种田 |
| `epic-solemn` | 宏阔庄重 | 战争、史诗幻想、文明冲突 |
| `noir-hardboiled` | 冷硬都市 | 犯罪、异能都市、灰度调查 |

先运行 `style_profile.py --list` 查看预设，用 `--show <标识>` 预览。确认后应用：

```bash
python3 <skill-dir>/scripts/style_profile.py \
  --project <项目目录> \
  --primary suspense-tight \
  --secondary lyrical-restrained \
  --notes "推理段保持冷静，人物独处时才允许抒情"
```

不要为了显得复杂而混合。两种风格在叙事距离、时代词汇或喜剧温度上冲突时，只保留主风格。

## 作者手法转译

用户提到知名作者时，不把“像某作者”直接当成写作指令。先根据用户提供的样章，或公开可访问的访谈、评论和合法文本，制作手法转译卡：

1. 写明参考范围和来源，不凭印象概括整位作者。
2. 只抽取叙事距离、句式节奏、词汇层级、对白机制、意象组织、信息控制、幽默机制和场景转换等可描述手法。
3. 每项写清“功能、适用场景、使用频率、失控风险”，不要只写形容词。
4. 明确排除标志性措辞、固定句式、著名比喻、角色关系、世界设定和段落级复刻。
5. 将多位作者的参考拆成互补功能，例如“一位提供对白机制，另一位提供悬念控制”，不要求混合成仿作声线。

手法卡建议结构：

```markdown
- 参考范围：公开访谈与用户提供的短样章
- 核心功能：让日常对白同时承载权力试探
- 叙事距离：第三人称限知，判断紧贴视角人物
- 句式节奏：铺垫用中句，转折落在短句
- 对白机制：答非所问暴露利益冲突；每场最多一次明显机锋
- 意象组织：每个小篇章控制一个重复物象，意义随人物选择变化
- 信息控制：线索首次出现时公平可见，解释延迟不超过当前小篇章
- 失控风险：全员说话同声、金句过密、为了留白省略必要因果
```

把完成的卡片保存为 UTF-8 文件，再应用自定义档案：

```bash
python3 <skill-dir>/scripts/style_profile.py \
  --project <项目目录> \
  --custom-id restrained-dialogue \
  --custom-title "克制对白与公平悬念" \
  --custom-file <手法卡.md>
```

## 连载一致性

写每章前读取 `canon/style-profile.md` 和最近两章。动笔前只保留五个可执行锚点：叙事距离、句式节奏、对白机制、意象密度、禁用倾向。正文完成后按这五项复核，不用统计指标机械伪装风格质量。

人物声音优先于统一文风。不同人物通过注意对象、利益、回避方式和句法习惯区分，不靠人人共享的金句或口头禅。

中途明显换风格会改变读者预期，属于重大决策。作者确认后记录到 `state/decisions.json`，再运行 `style_profile.py ... --confirmed`；局部场景因压力改变句长或温度不算换风格。
