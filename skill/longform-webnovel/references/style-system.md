# 语言风格选择与手法转译

## 选择原则

语言风格服务故事承诺，不代替剧情推进。新书在故事合同阶段选择一个主风格；确有必要时再加一个辅风格。主风格决定可读性、叙事距离和句式底盘，辅风格只调节局部质感。

| 标识 | 名称 | 适合的核心体验 |
|---|---|---|
| `fanqie-clean` | 清晰推进 | 通用番茄节奏、升级、经营、都市成长 |
| `suspense-tight` | 冷峻悬疑 | 推理、规则怪谈、秘密调查 |
| `warm-grounded` | 温暖烟火 | 年代、家庭、日常经营、群像 |
| `witty-dialogue` | 机锋轻喜 | 轻喜剧、欢喜冤家、职场或团队互动 |
| `lyrical-restrained` | 克制抒情 | 情感、成长、带文学质感的幻想 |
| `historical-plain` | 古意白描 | 历史、古言、权谋、种田 |
| `epic-solemn` | 宏阔庄重 | 战争、史诗幻想、文明冲突 |
| `noir-hardboiled` | 冷硬都市 | 犯罪、异能都市、灰度调查 |

先运行 `style_profile.py --list` 查看预设，用 `--show <标识>` 预览。确认后应用：

```bash
python3 <skill-dir>/scripts/style_profile.py \
  --project <项目目录> \
  --primary suspense-tight \
  --secondary lyrical-restrained \
  --notes "推理段保持冷静，人物独处时才允许抒情"
```

不要为了显得复杂而混合。两种风格在叙事距离、时代词汇或喜剧温度上冲突时，只保留主风格。

叙事距离同时决定叙述者的知情权限与说话方式。限知段落不能补出视角人物未知的答案；已确认的全知、说书或带评论的旁白，可以概述场外背景、表达判断与幽默，不默认压成严格限知。人物自己的推断、他人自述与叙述者可确认的事实仍须区分；若后文保留某项疑点，前文不能把它断言成相反的定论。直接抒情、解释和回返细节先看功能与上下文，不仅凭句型删除；复现后意义改变，也不能当作无功能重复。更改叙述权限仍按文风变更处理，不为补情绪临时换视角。

## 作者手法转译

用户提到知名作者时，不把“像某作者”直接当成写作指令。先根据用户提供的样章，或公开可访问的访谈、评论和合法文本，制作手法转译卡：

1. 写明参考范围和来源，不凭印象概括整位作者。
2. 只抽取叙事距离、句式节奏、词汇层级、对白机制、意象组织、信息控制、幽默机制和场景转换等可描述手法。
3. 每项写清“功能、适用场景、使用频率、失控风险”，不要只写形容词。
4. 明确排除标志性措辞、固定句式、著名比喻、角色关系、世界设定和段落级复刻。
5. 将多位作者的参考拆成互补功能，例如“一位提供对白机制，另一位提供悬念控制”，不要求混合成仿作声线。

同批参考章节内也要核对后文是否修正了前面的判断。抽取成功机制时，同时记下它依赖的巧合、叙事夸张和未解决条件；别把角色自信的解释、价值偏见或传说当成作者已经证实的规则。涉及战力、合作与误判的具体转译见 [conflict-and-inference.md](conflict-and-inference.md)，仅按当前问题选用。

手法卡建议结构：

```markdown
- 参考范围：公开访谈与用户提供的短样章
- 核心功能：让日常对白同时承载权力试探
- 叙事距离：第三人称限知，判断紧贴视角人物
- 句式节奏：铺垫用中句，转折落在短句
- 对白机制：答非所问暴露利益冲突；每场最多一次明显机锋
- 意象组织：每个小篇章控制一个重复物象，意义随人物选择变化
- 信息控制：线索首次出现时公平可见，解释延迟不超过当前小篇章
- 失控风险：全员说话同声、金句过密、为了留白省略必要因果
```

把完成的卡片保存为 UTF-8 文件，再应用自定义档案：

```bash
python3 <skill-dir>/scripts/style_profile.py \
  --project <项目目录> \
  --custom-id restrained-dialogue \
  --custom-title "克制对白与公平悬念" \
  --custom-file <手法卡.md>
```

## 个人声音证据

用户提供本人原创样稿或亲手修改的“改前—改后”文本时，读取 [prose-naturalization.md](prose-naturalization.md)。从真实改动提取保留倾向、删除倾向、替换规律、人物声音和收尾习惯，并附短证据与置信度；不要仅凭一篇文本概括稳定文风，也不要把未经确认的 AI 初稿循环训练成项目声音。

个人声音证据优先于通用预设，但只覆盖有证据的维度。作者确认的朱雀低 AIGC 片段可以作为候选声音证据，必须同时绑定报告版本、送检正文版本和适用场景；低值本身不能证明“更像真人”，未确认的片段只能作为待审样本。其余维度继续使用主风格参数。若作者后续修改与现有规则冲突，先区分场景用途，再更新规则和适用范围，不能简单累加互相矛盾的禁令。

## 连载一致性

筹备每章前读取 `canon/style-profile.md` 和最近两章。风格沿用五个锚点：叙事距离、句式节奏、对白机制、意象密度、禁用倾向；不要求每章重新列五条指令。有作者确认样本时，选适用于当前人物与场景的少量短原段，说明值得保留的叙述口气、幽默或对白习惯，按 [writer-context.md](writer-context.md) 交给写手。没有合适样本时沿用既有有效正文或暂定风格，不编造作者证据，不把样本句法逐句套入新稿。正文完成后再按已有锚点复核，不用统计指标机械伪装风格质量。

人物声音优先于统一文风。不同人物通过注意对象、利益、回避方式和句法习惯区分，不靠人人共享的金句或口头禅。自然化不是另一个预设风格；它负责防止通用风格把所有人物压成同一种正确、清楚、善于总结的声音。改前改后对照这些已有锚点；如果人物的幽默、主观判断或叙述口气被磨成流程说明，恢复相应表达，不用“更简洁”抵消声音损失。

预设中的节奏、句式和细节示例是倾向，不是逐章配额；已确认旧档案若仍写有“中段升级、后段回报”或“每章真实状态变化”，按当前篇幅模式在事件或阶段上理解，不改变作者已确认的声音，不为切章另造结构。

中途明显换风格会改变读者预期，属于重大决策。作者确认后记录到 `state/decisions.json`，再运行 `style_profile.py ... --confirmed`；局部场景因压力改变句长或温度不算换风格。
