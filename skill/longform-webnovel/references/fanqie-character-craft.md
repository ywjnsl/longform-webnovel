# 番茄人物刻画（写作与审稿）

把平台公开的人物课转成可观察检查。角色卡用于核对选择，情绪表达按人物与叙述声音判断，允许直接心理和旁白。

本模块依据番茄小说网作家课堂《告别千人一面：带你写出有血有肉的人物》。平台口径可能调整；作者提供更新课时以更新页为准，改本文件要点，不整段搬官方例文。

适用：`fanqie-short-story` 写节、审稿默认执行。`serial` 在作者按番茄投稿来写时同样执行。与 [fanqie-signing-quality.md](fanqie-signing-quality.md) 一起用：签约看合规与收口，本文件看人是不是活人。新书开篇能否留人见 [fanqie-new-book.md](fanqie-new-book.md)。

已有角色隔离、意图 JSON、配角弧光账本仍有效。本文件补的是：**选择要解释得通、赢要有代价、情绪表达可信、新人出场能认、对白能听出是谁。**

## 三种失败，对上现有审稿类

读者觉得「假」「入不了戏」时，先对号，再找逐字证据：

| 失败 | 正文长什么样 | 审稿类 | 改法 |
|---|---|---|---|
| 人设漂移 | 关键行为无法从其经历、性格、欲望、当场处境解释；为了过情节突然换人 | 编辑 `character` / `continuity` | 改选择或改处境，不事后用旁白圆 |
| 千人一面 | 多人同一冷静度、同一句长、同一套反驳；去掉名字分不清谁在说话 | 自然度 `same-voice` | 按利益、身份、回避方式重做对白 |
| 情绪表达失效 | 反复命名同一情绪，却没有让读者理解人物此刻的感受；需结合上下文指出阅读问题 | 自然度 `over-explanation` + `generic-reaction` | 按问题选择删重复、补必要心理或具体反应；直接说出情绪有效时保留，不要求换成身体动作 |

逻辑通顺但读着呆板，优先查这三项，不要先去扩写日常。

## 方法一：角色卡是核对器，不是人设演讲

重要角色必须有 `cast/{id}/SKILL.md` 与 `state.json`。写每一拍之前，关键行为要能从下列四项解释：

1. 经历（`memory` / scars / 已知事实）
2. 性格与边界（`wouldNeverSay`、不能轻易跨越的边界）
3. 欲望（`wantNow`、`ownWant`）
4. 当下处境（谁在场、手里有什么、制度允许什么）

对不上就记为试图失败，或让角色付代价后才改变；禁止为推进把人改成万能工具。为制造冲突让高智商角色犯低级错误，按 [fanqie-consistency.md](fanqie-consistency.md) 先改剧情，不改人。

长篇每隔一个小兑现窗口回看一次 `cast-arcs.json` 的最近选择。短故事每节结束核对上场人：有没有做出完全不像此人的事。

## 方法二：重要胜利必须有真实代价

主角可以打脸、拿资源、过关，但**本节的重要胜利**至少付出一样读者看得见的东西：时间、身体、名额、关系、机会、把柄，或救 A 就救不了 B。

「两份奖励都拿到、对手也顺手解决」视为走流程赢，编辑维度用 `character` 或 `promise`，至少 `medium`。

代价必须进入状态：写进 `cost`、`scars`、`stateDeltas` 或关系 `cost`。只在对白里说「我付出了很多」不算。

## 方法三：生活体感服务人物，不是水日常

压力、疲惫、疼痛或吃穿的窘迫，可以由身体反应、心理、对白或必要旁白表达。跪完站不稳、肩袋勒印、熬夜眼干只是可选例子，不要求每个反应改变下一步行动。

吃饭、逛街、天气或安静停留若承载人物牵挂、关系、气氛或声音，可以保留。仅为“增加生活感”而新增无关场面、重复已知信息，且有具体阅读拖累时，才按 `padding-expansion` 定向处理，不因主线状态未变就整场删除。

## 方法四：新人出场带标签，对白能认人

长篇前 20 章先稳住核心角色，不要一上来砸十几个人名。短故事改成：**前两节先稳住本合同 `onStage` 的核心人**；`cameo` 出场也要当场能认。

新角色第一次被视角看见时，三句话内交代清楚（可拆在动作里，不必自我介绍）：

1. 他是谁（身份或可再认的身体锚）
2. 跟场上谁有关系
3. 此刻为什么重要（要什么、能改变什么）

对白必须有辨识度：身份、利害、回避方式不同，则句长、用词、敢说的话不同。写手不得让两人共用同一套冷静反驳。对应 `wouldSay` / `wouldNeverSay`。

## 写节与审稿必答

写 `editor.diagnosis` 时，人物相关用一两句覆盖：

1. 本节关键选择能否从其角色卡解释？有没有为过情节改人？
2. 若有胜利或过关，代价写在哪句、进了哪条状态？
3. 情绪表达是否符合人物与处境？直接心理、对白、身体或旁白是否有效，有无重复或读者难以理解的地方？
4. 新出场的人能否不看名字认出是谁？多人说话能否区分？
5. 对白是否符合人物口气和当前关系？直说或绕开是否在此处有效？有没有因重复背景、标准反驳或脱离人物处境的固定台词造成具体阅读问题？不按某句是否直白、是否改变行动单独判失败。
6. 叙述和对白有没有重复已经清楚的意义，或越过知情边界替读者锁死答案？有具体问题才引用原句定向处理；必要心理、判断和有辨识度的评论可以保留。

读者若觉得「工具人」「假」「没感觉」，`moments` 必须引用造成该感受的实际原文，说明阅读代价，不能预设问题必定来自旁白或只写「人物不够立体」。

## 常见借口

| 借口 | 处理 |
|---|---|
| 「短故事没篇幅写生活」 | 按人物与本节职责取舍，必要心理、日常对白或细节都可承载生活感，不分配身体反应配额 |
| 「旁白写悲痛比较快」 | 核对是否可信、是否重复；直接表达有效就保留，不能因命名情绪而优先删 |
| 「配角只出场一次，不必辨识」 | `cameo` 也要身份、关系、此刻用处；不必完整弧 |
| 「赢了才爽，加代价会泄劲」 | 无代价的赢是走流程；代价本身可以成为下一拍压力 |
| 「角色卡写过了，正文可以漂移」 | 卡是核对器；漂移先改正文或付代价，不靠后文解释 |
