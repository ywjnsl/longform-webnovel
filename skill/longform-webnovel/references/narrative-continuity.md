# 事件之间的情绪与人物连续性

适用于 `serial`、`novella` 与 `fanqie-short-story` 的初稿、关系转折、阶段转换和“情绪平、人物像工具”的结构诊断。关注前一件事怎样改变后一件事，不规定每章必须发生反转、损失、成长或关系升级。

## 写前沿用，写后取证

沿用故事合同、角色状态、当前事件和已经写成的正文。只找与当前选择有关的前因：这个人原先想要什么，上次经历留下了什么，现在因此如何理解眼前的人或事。能从已有材料回答时，不另建场景拍清单，不给四句写前卡增加必填栏，也不预写每章情绪曲线。

重要前因可能早于最近两章。角色状态中的记忆或关系指向更早事件时，回查那一处正文；不重读全书，也不把刚结束一章当作情绪重新归零的边界。一次感动可以延续为信任、试探、负担或躲避，不一定当场说开。

写后只记录正文已经证明的变化。计划中的和好、原谅、接纳或成熟，不提前写入正史；没有发生变化时沿用原状态，不为完成记录制造新事件。

## 按当前问题选用机制

| 当前阅读问题 | 可用机制与检查 | 适用边界与失控风险 |
| --- | --- | --- |
| 当场很激动，下一次相处却像没发生过 | 检查前事是否改变称呼、求助、拒绝、信任或回避。延续最相关的后果即可；不必每次回忆原场面。 | 关系转折后使用。帮助不自动等于爱情、原谅或永久效忠，改变也可以缓慢或矛盾。 |
| 危险只有抽象的生死，读者不知道人物在失去什么 | 在既有行动或闲谈中让生活愿望具体，再看后来的风险威胁了哪一部分。各人想象的未来可以不同。 | 告别、失去或选择分岔时使用。愿望可以被保护、实现或改变，不为下一页摧毁而临时补幸福日常。 |
| 成长只有一句“他懂了” | 看人物重新面对旧目标、资格、物件或关系时，注意与感受是否改变。新理解可以与旧欲望共存。 | 经历足以影响价值判断时使用。没有旧目标就不临时造象征物；一次领悟不等于全部性格翻新。 |
| 每次获胜都顺带解决所有问题 | 分别看个人做成什么、任务完成到哪、其他人得到或失去什么、关系留下什么。不同层面的结果可以不同。 | 团队或多方行动时使用。允许完整胜利，不强制牺牲；不让配角随机受害来给主角增加深度。 |
| 新来者立刻成为所有人的知己 | 区分正式身份、初步善意、专业信任与私人亲近。不同人按自己的依据接纳或保留距离；相信此刻真诚，也可以继续观察以后是否可靠。 | 加入组织、家庭或团队时使用。不要求固定四阶段，也不靠人人先欺负新人制造进度。对自己人护短不等于整体公正。 |
| 换阶段后能力突然清零，或什么都会 | 让旧能力在新问题上有用途，同时延续已成立的短处。配角的知识、资源或拒绝应能改变解法。 | 新任务与新环境出现时使用。不会的东西要有来由，不随用随加；强项不能自动替代所有专业训练。 |
| 宝物、钱或资格只是一行升级播报 | 区分得到、辨识、搬运、加工与使用；只展开真正影响下一步的门槛。允许用既有经验找到有限替代方案。 | 实际存在转换条件时使用。已有可用收益要兑现，不把所有奖励拖成无尽手续或物品目录。 |
| 旧人回场或大局变化只靠突然宣布 | 看离场人物与组织此前在做什么，结果怎样改变当前可用资源、规则或生活选择。新问题可来自旧事件的收尾。 | 重逢和阶段转换时使用。无需演出全部场外过程，不声称所有相遇必然；新谜团不能替代旧承诺的兑现。 |
| 后置揭示只剩作者藏答案 | 先给可观察行为或事实，再让新信息改变其意义；检查当时的知情范围与叙述权限是否支持延迟。 | 信息差、关系或动机揭示时使用。不隐藏视角人物当时必然知道且会想到的关键事实；别人自述不自动成为确定正史。 |

这些是诊断入口，不是每场逐项执行的模板。没有相应阅读问题或情境时不调用；使用频率跟着真正的关系、目标或阶段变化走。

当人物拒绝看似更好的出路时，先看他真正要保住的是收入、职位，还是某种身份、技艺或理想。后者未必能用更高待遇替代；降职也可能让他重新做想做的事。害怕、疲惫、对组织现状失望，可以与继续相信某项原则并存。用具体取舍显出这种区别，不把坚持一律解释成不懂利害，也不把一次挫折直接写成信念崩溃。别人的坚持可以使主角开始自问，不必当场交出人生答案；信念也可以被后续证据改变。

## 原创微例：作用落在前后联系

一名学徒原想拿到资格证后离开维修站。一次抢修中，他独自排除了故障，却没能按时恢复整片街区供水。回站后获得证书，他先问的变成了自己能否参加下一轮值班；他仍嫌工资少，也仍想去大城市。变化在旧目标的新意义，不必加一段“终于理解责任”的总结，更不必临时让同伴死亡。

同样是老员工给学徒留下夜班饭，可以表示愿意照顾新人；愿意把关键检修交给他，则还需要专业判断的依据。两个动作不必同时出现，也不必各占一章。若原稿只是写夜班饭，就不能在语言润色时擅自补出关键任务或把关系记成完全信任。

## 修订时分清结构与语言

人物情绪显得平时，先顺读相关事件：已有触发是否成立，当前反应是否属于这个人，后续感受或相处是否承接了前事。不是每项都要演出，但不能只把“难过”替换成握拳，便宣称解决了缺少前因或后果的问题。

- **联系已经存在，只是表达被遮住：** 在授权段落内保留或就地换写必要心理、对白与叙述；动作无法表达“他把这件事与旧经历联系起来”时，不硬换成微表情。
- **缺少事件或关键选择：** 记为结构问题，按原有修订范围处理。语言改稿不能补造死亡、背叛、承诺、误判、回忆或重大牺牲；朱雀未标红段仍冻结。
- **原稿已有效：** 保留原文。不为满足本文件追加物件、生活闲笔或关系变化，不借恢复情绪给短章补字。

快慢也按事件权重取舍：旅程和熟悉流程可以概述，关键选择可以展开，脱险后的闲谈可以承载愿望和关系。安静不自动等于注水；连续紧张不自动等于推进。一件事跨章时，战斗、撤离、回报与心理余波可以分布在不同章，不为章界重置情绪或另造完整高潮。

## 写入已有状态，保留证据层级

只在有变化时使用现有字段，不加新的 JSON 门禁或必填配额：

- `cast/{id}/state.json` 的 `emotion` 记当前感受与触发；`memory` 留能解释以后选择的重要事件，近期小事不应挤掉仍有效的关系转折。
- `relationships` 的既有描述写清已成立的信任、戒备或依赖及其依据；不只写笼统的“好感增加”。`wantNow` 保留当前目标，不因获得新理解就自动删除旧欲望。
- 长期稳定的约束才进入角色 `SKILL.md`；一次表现暂记在状态里。区分已发生行为、角色给出的理由、他人的评价与尚未证实的推断，后文证据可以修正解释。
- 回报已兑现才按 [reward-system.md](reward-system.md) 记录收益、代价和状态变化；情绪通过角色状态延续，不把所有感受硬写成战果。
- 编辑在现有 `character`、`causality` 或 `continuity` finding 中说明具体断点与读者代价；尚未落定的跨章变化不按缺项阻断，判断范围跟着事件与本次授权走。

对抗结果、同阵营利益、有限救援或名声误判需要更细诊断时，读 [conflict-and-inference.md](conflict-and-inference.md)。沿用本文的状态记录和证据层级，不为新增机制另建字段。
