# 场面：环境、人物、动作

意图 JSON 只说明角色想做什么。写手必须把裁定后的意图写成**可看见的场面**，不能直接变成对白加结果摘要。风格档案的五个锚点仍然有效；本文管空间、身体和过程。

场面要让读者辨明空间、人物和牵挂；对白本身也能承载一场戏。已有定位时允许连续对白，不用衣着和手部动作填满每个间隙。

场面定位不清时，在已有写前卡中核对以下四项；明确的沿用，不另加一份清单：

- 空间：出口、光线、距离、能伤人或能藏人的东西；
- 身体锚：在场主要人物此刻可被认出的一点（步态、手、衣料、伤、气味）；
- 本拍动作：意图 → 过程 → 代价 → 对方反应；
- 视角过滤：此人会先抓住哪一口感官，会忽略什么。

四行只核对这场是否站得住，不是正文的四段，也不规定环境、身体、动作、对白的出现顺序。已由上文建立的信息无需重新介绍。

正文从他正在做的那一下写起。门、灯、袖口、手上的东西嵌在这一下里，不先交一份现场说明。他多看的那一样可以暂时没用，但必须是这个人会看的。换一本书仍成立的杯子、天气和微表情，不拿来装真人。

## 环境

只写视角人物此刻用得上的空间，不写导游词、地理志或纯气氛排比。

- 入场先给方位和远近：门在哪、人站哪、身上哪一件衣服、手里做什么、什么挡住退路。读者要能在脑子里站住，并跟着他看。
- 说话的时候屋子还在。灯、桌、门口、这件衣服、这件工具，从他眼里写出来。这些是画面，不是旁白介绍，也不另起一段风景。
- 衣着写他会注意的一点：班服、袖口、鞋上的水、衣料碍不碍事。不写从头到脚的服装清单。
- 对白与空间保持连续；人物可以静止，不为每句话插入手部动作。确有移动时，让读者理解位置怎样改变。
- 感官细节按视角注意与场景需要取舍，不固定每次的种类和数量。这个地方特有的可以留，用来让读者站进来。换到任何房间都成立的空景删掉。四时风光巡演不行。
- 现场镜头跟随人物此刻看见、听见、闻到或身体感到的东西，不用「整个大厅陷入死寂」这类泛化反应代替具体现场。她恨谁，这一眼就把谁写得可憎；这是她此刻的偏见，不能写成已证实事实。需要心理时可以写完整念头、自我辩解、偏见或联想，也可以被打断；详略来自人物注意，不把半句当统一格式。限知段落不补出此人未知的答案；已有全知或评论型旁白时，知情权限按 [style-system.md](style-system.md) 执行，不把它默认改成限知。
- 一个细节能同时干两件事就更好。门既是出口，也是下一步要付的代价；衣料既让人认出他，也碍着这一下动作。只为凑画面、和这场无关的景物仍然删掉。
- 环境要能还手：滑、挤、暗、湿、吵、烫、有人接近。
- 换场时用一个身体动作带过去（推门、踩阶、被拽进雨里），不要空行后另起风景段。禁止无过程换城，见 [fanqie-consistency.md](fanqie-consistency.md)。
- 短故事更紧：同一场所不重复介绍；第二次出现只写相对上次变了什么。

禁止：开篇先写「夜色如墨」「山风猎猎」再让人物出场；用一段世界设定代替「现在这间屋子危险在哪」。

## 人物

第一次在读者眼前出现，给一个能再认的身体锚，不要脸谱说明书。

- 优先写正在做的身体：怎么站、手往哪放、呼吸、步子轻重、衣料是否碍事。外貌只留一样别人会记住的。
- 之后只在关系、压力、伤势或身份变化时再写身体。每章给每个配角重新化妆是注水。
- 不同人物注意不同部位。修士看对方的手和气息，账房看衣料和印章，孩子看身高和脸色。
- 情绪按人物当下感受与本作品的声音表达，可以直说、停留，也可以改变下一步。表情、动作、心理、比喻和旁白承担不同信息时可以并写，重复同一个意思并损害阅读时才删。“眼中闪过”“嘴角勾起”“深吸一口气”“不禁”“心中暗道”“指节一白”等仅是复核入口，不是禁用词；只有成组替代具体人物感受或造成重复时才定向处理，不机械换成另一套微表情。站位、衣着和手上的活按场景需要写，不要求每次反应推动行动，也不为人物补齐身体反应。番茄短故事同样按 [fanqie-character-craft.md](fanqie-character-craft.md) 核对实际效果；相关方法见 [chapter-craft.md](chapter-craft.md)，自然化边界见 [prose-naturalization.md](prose-naturalization.md)。
- 遵守角色已确认的表达边界；不愿说出口的内容可以保持沉默、改口，或由符合叙述权限的心理与旁白呈现，不强迫改成身体泄漏。

禁止：入场一段「剑眉星目、气质出尘」；用口头禅代替体态；所有人共用同一种冷静微表情。

## 动作

关键动作可用以下四项检查读者能否理解过程与后果，不要求每次动作走满四拍。日常动作可以一句带过；关键对抗写清真正影响结果的阻力，不为完整格式给每一下添加代价。

1. **意图**：他要完成什么，此刻身体朝向哪。
2. **过程**：手、脚、器械或法力实际怎么走；有中间阻力。
3. **代价**：力尽、破绽、暴露、耗材、违规风险。修仙尤其不能只报招式名。
4. **反应**：对方或环境怎么还手；下一拍的空间因此改变。

群殴、追逐、破境、抢物都拆成可见的来回，不要一句「大战三百回合」或「他突破了」。

- 同时最多让读者盯住两个人的身体接触或相对位移。第三人用余光、声音、地面震动入场。
- 失败也要有过程：滑、慢半拍、抓空、被规则弹回。被否决的意图必须写成试图失败，不能改写成干脆没动手。
- 对白打断动作时，人还在原来的空间里。说完话，手和距离不能瞬移。
- 连续短动作若形成单调清单、使过程难懂，再按实际阻力或回应重组；不按三个同类句式自动判错，也不为变句式补阻力。
- 动作先后按语义写清，不按动作数量套连接词。独句段和比喻依据人物声音与局部节奏取舍；形成单调的动作清单或金句墙时再重组。

禁止：万能微表情顶替动作；技能名 + 结果；为凑字数重复同一击打。

## 打斗（加厚）

对打、追逐、围杀、破境抢关、以武压人，都算打斗。这类场面**大幅度加厚**：空间、身体、过程要比日常对话场密一截，篇幅也明显更长。读者要看清决定胜负的攻防如何发生，不跳过关键过程。

日常与打斗的详略由场景重心决定，不按感官数量或回合数配额；关键过程清楚后即可收束。

### 加厚什么

- **空间保持可追踪。** 距离、高低、脚下、退路、能当武器或障碍的东西，随招改写。墙、柱、雨、碎石、人群、阵纹都要还手，不能当背景板。
- **身体状态保持连续。** 站位、重心、握器、呼吸、旧伤、新伤、衣料撕开或被血黏住。伤势、疲劳或感受须符合实际攻防和法则，不为每一记分配一处伤或身体反应；有损伤则延续其影响。
- **关键攻防交代过程与后果。** 意图、过程、代价、反应是检查角度，不是每一击都必须写全的模板。详写决定胜负的攻防，重复招式可略写效果；阻力来自对手与法则，不机械追加偏斜、慢半拍或身体反应。
- **对白让路。** 打斗中途少说话；要说就短，且不让人瞬移。旁白解释、战力对比、路人惊叹能删则删，把字数还给过程。
- **围观第三人用余光进。** 同时只盯两人相对位移；第三人用尘土、破风、地面震动、兵器落地声入画，再切过去。

### 节奏与篇幅

- 关键对决（生死、破境、当众丢脸、抢走信物）按实力、策略与既有铺垫决定来回，不设最低轮数；写清决定结果的过程，不为加厚延长本该结束的对抗。
- 小冲突（推搡、试探、点到为止）写到其选择或代价可理解即可，不按轮数摊开。
- 失败、溃逃、被否决的硬闯，过程比胜利更要写细：哪一拍慢了、哪处破绽、身体哪先垮。
- 加厚不是注水。多出来的句子必须改距离、伤势、重心或下一招选项。同一击换同义词再打一遍，删。也不要把对打切成独句金句墙，或在每一记后补战术字幕。

实力与胜负不匹配、换一种交手方式就忽然无敌，或救援像凭空出现时，按需读 [conflict-and-inference.md](conflict-and-inference.md)。先检查任务、条件、协作和知情范围，再决定是否缺少动作过程；不靠延长打斗修补因果。

### 修仙 / 力量战额外

- 法力、灵气、领域要落到身体和地面：热、压、麻、光从哪来、脚下一滑还是空气变沉。
- 越阶、禁术、旁门必须写出规则代价的身体版（经脉、五感、失控范围），不能只在事后口头补一句。
- 破境穿插在对打里：失控的力会打偏、震伤自己或波及旁人，不要停战做升级蒙太奇。

禁止：大战三百回合；他使出某某招，对手吐血败了；围观全员「好强」；用属性表代替身体过程。

## 写完自检

主要场面核对：人物和空间是否可理解，关键过程与后果是否清楚？缺什么补什么，不因此给每拍加代价，也不把补动作设为心理与对白的前置条件。

打斗场再检查决定结果的攻防是否可理解、空间与伤势是否连续；缺关键过程时补足，不为每一记另添变化，不用路人反应充数。
