# 场面：环境、人物、动作

意图 JSON 只说明角色想做什么。写手必须把裁定后的意图写成**可看见的场面**，不能直接变成对白加结果摘要。风格档案的五个锚点仍然有效；本文管空间、身体和过程。

写每个上场场景前，在写前卡之外补四行：

- 空间：出口、光线、距离、能伤人或能藏人的东西；
- 身体锚：在场主要人物此刻可被认出的一点（步态、手、衣料、伤、气味）；
- 本拍动作：意图 → 过程 → 代价 → 对方反应；
- 视角过滤：此人会先抓住哪一口感官，会忽略什么。

删掉这四行后若场面仍能成立，说明还在写提纲，没写正文。

## 环境

只写视角人物此刻用得上的空间，不写导游词、地理志或纯气氛排比。

- 入场先给方位和远近：门在哪、人站哪、什么挡住退路。读者要能在脑子里站住。
- 感官每次只强调一到两样，且必须改注意力、行动或判断。温度、气味、光线、声响可以；四时风光巡演不行。
- 环境要能还手：滑、挤、暗、湿、吵、烫、有人接近。装饰性景物删掉。
- 换场时用一个身体动作带过去（推门、踩阶、被拽进雨里），不要空行后另起风景段。
- 短故事更紧：同一场所不重复介绍；第二次出现只写相对上次变了什么。

禁止：开篇先写「夜色如墨」「山风猎猎」再让人物出场；用一段世界设定代替「现在这间屋子危险在哪」。

## 人物

第一次在读者眼前出现，给一个能再认的身体锚，不要脸谱说明书。

- 优先写正在做的身体：怎么站、手往哪放、呼吸、步子轻重、衣料是否碍事。外貌只留一样别人会记住的。
- 之后只在关系、压力、伤势或身份变化时再写身体。每章给每个配角重新化妆是注水。
- 不同人物注意不同部位。修士看对方的手和气息，账房看衣料和印章，孩子看身高和脸色。
- 情绪落在可观察处：嗓音发干、指节发白、把杯子转了半圈。禁止「眼中闪过」「嘴角勾起」「深吸一口气」当默认表情包。
- `wouldNeverSay` 的内容不得说出口；压抑改写成身体泄漏或改口，不改写成作者旁白。

禁止：入场一段「剑眉星目、气质出尘」；用口头禅代替体态；所有人共用同一种冷静微表情。

## 动作

一次有效动作写清四拍，缺一拍就还是摘要。

1. **意图**：他要完成什么，此刻身体朝向哪。
2. **过程**：手、脚、器械或法力实际怎么走；有中间阻力。
3. **代价**：力尽、破绽、暴露、耗材、违规风险。修仙尤其不能只报招式名。
4. **反应**：对方或环境怎么还手；下一拍的空间因此改变。

群殴、追逐、破境、抢物都拆成可见的来回，不要一句「大战三百回合」或「他突破了」。

- 同时最多让读者盯住两个人的身体接触或相对位移。第三人用余光、声音、地面震动入场。
- 失败也要有过程：滑、慢半拍、抓空、被规则弹回。被否决的意图必须写成试图失败，不能改写成干脆没动手。
- 对白打断动作时，人还在原来的空间里。说完话，手和距离不能瞬移。
- 连续三个「他……。他……。他……」短动作包要重组，改成过程里夹一句阻力或对方反应。

禁止：万能微表情顶替动作；技能名 + 结果；为凑字数重复同一击打。

## 打斗（加厚）

对打、追逐、围杀、破境抢关、以武压人，都算打斗。这类场面**大幅度加厚**：空间、身体、过程要比日常对话场密一截，篇幅也明显更长。读者要看清每一记怎么来、怎么挡、怎么疼，不能跳到胜负。

日常场仍是一两个感官细节；打斗场反过来：过程写够之前，不准收束。

### 加厚什么

- **空间每回合都要变。** 距离、高低、脚下、退路、能当武器或障碍的东西，随招改写。墙、柱、雨、碎石、人群、阵纹都要还手，不能当背景板。
- **身体一直在镜头里。** 站位、重心、握器、呼吸、旧伤、新伤、衣料撕开或被血黏住。每一记留下痕迹：擦伤、震臂、膝软、耳鸣、视野收窄。禁止打完还完好如初，除非法则明确如此。
- **每一记走满四拍。** 意图、过程、代价、反应都写成可见动作。过程要有中间阻力：偏了、慢了、被格开、被规则弹回。招式名最多点一下，真正占篇幅的是手、脚、器、力怎么走。
- **对白让路。** 打斗中途少说话；要说就短，且不让人瞬移。旁白解释、战力对比、路人惊叹能删则删，把字数还给过程。
- **围观第三人用余光进。** 同时只盯两人相对位移；第三人用尘土、破风、地面震动、兵器落地声入画，再切过去。

### 节奏与篇幅

- 关键对决（生死、破境、当众丢脸、抢走信物）至少拆成三轮可见来回，每轮改变空间或伤势。一轮解决的只适合碾压或偷袭，仍要把那一击的过程写清楚。
- 小冲突（推搡、试探、点到为止）也比对话场厚，但两轮内必须见选择或代价，不无限拆招。
- 失败、溃逃、被否决的硬闯，过程比胜利更要写细：哪一拍慢了、哪处破绽、身体哪先垮。
- 加厚不是注水。多出来的句子必须改距离、伤势、重心或下一招选项。同一击换同义词再打一遍，删。

### 修仙 / 力量战额外

- 法力、灵气、领域要落到身体和地面：热、压、麻、光从哪来、脚下一滑还是空气变沉。
- 越阶、禁术、旁门必须写出规则代价的身体版（经脉、五感、失控范围），不能只在事后口头补一句。
- 破境穿插在对打里：失控的力会打偏、震伤自己或波及旁人，不要停战做升级蒙太奇。

禁止：大战三百回合；他使出某某招，对手吐血败了；围观全员「好强」；用属性表代替身体过程。

## 写完自检

每个主要场面问三句：人站在哪？读者凭哪一点认出他？这一拍的过程有没有代价和反应？任一句答不上来，先补场面，再考虑加对白或内心。

打斗场再加两句：这一记有没有中间过程？空间或伤势有没有因这一记改变？答不上来就还是摘要，继续加厚，不要用对白或路人反应充数。
