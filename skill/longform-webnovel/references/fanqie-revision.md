# 番茄自检与改稿边界（写作与审稿）

把平台公开的改稿问答转成可观察检查。不保证越改越好，也禁止把「通文重写」当成默认动作。

本模块依据番茄小说网作家课堂 2026-04-09《作品越改越乱？学会自检，稳住节奏与大纲！》。平台口径可能调整；作者提供更新课时以更新页为准，不整段搬官方例文。

适用：修订诊断、作者说越改越乱、看不出哪章有问题、要求按数据或评论改已提交正文。写新章仍先走写前卡；本文件管**已有正文要不要动、动多大**。与 [performance-feedback.md](performance-feedback.md)、[prose-naturalization.md](prose-naturalization.md)、[approval-policy.md](approval-policy.md) 一起用。

## 先分问题，再决定范围

通读出问题的章，先归类，再选手术范围。禁止一边读一边整章重写。

| 问 | 落点 | 改法 |
|---|---|---|
| 故事本身没看点，还是句子没写清楚？ | `promise` / `structure` vs `line` | 结构问题先改选择与代价；句子问题只改证据段 |
| 人设没立住，还是中途崩了？ | [fanqie-character-craft.md](fanqie-character-craft.md) | 没立住补选择；崩了改这一拍或处境，不事后旁白圆 |
| 行为对不上此人逻辑？ | [fanqie-consistency.md](fanqie-consistency.md) | 「不会但剧情需要」时改剧情，不改人 |
| 单独一章改就够，还是要动 3–5 章、甚至十几章？ | 范围卡 | 超出单章且伤正史，按重大决策问作者 |

每一章当作独立内容再问两句：有没有看点？有没有往下翻的理由？都没有，先查空转，不先扩写。

顺读时标出卡顿句：通常是句太长或修饰不当。只改那些句，不借机重写全章。

## 自检：别只靠作者记忆

作者自己看不出问题时，用已有审稿角色，不另发明评分：

1. **冷读者三问**（可把主角名暂时换成陌生称呼再读）：他叫什么、他想干什么、他正在做什么。答不上来，入口或本章目标失败。
2. **读者模拟**：只报告哪里枯燥、哪里出戏、还想不想翻下一章。
3. **数据**（作者提供后台时）：追更、完读、评论按 [performance-feedback.md](performance-feedback.md) 定位。多人重复且与核心走向无关的点，才列入可改；个别人设偏好或与主承诺冲突的要求，不改合同。
4. **同字数段比节奏**：可按 [market-research.md](market-research.md) 看同类样本在相近篇幅写的是主线还是支线、推进快还是慢。只比密度与落点，不搬别人的情节、人名或场面。

反馈和数据只是展示面。必须自问：不改会怎样、改是大改还是小改。没有结论不得动手。

刚交的章，作者说某处差点意思，可以小改。后续正史已接上、又不伤核心走向和读者体验的，默认不动。

## 越改越乱：先定骨架，再动刀

把握不了改完之后怎么接后文，就不要改。选项交给作者：往下写练笔，或把该段剧情推倒重写。禁止在后文已写出时，只改开头几章却不重接时间线、伏笔和法则。

| 规模 | 可以做什么 | 禁止 |
|---|---|---|
| 小毒点、单章 | 删改那一处；朱雀未标红段落冻结 | 借小改重写全章或新开场面 |
| 连续数章的大剧情 | 先列为重大决策；作者确认后才能动 | 默默改前面、让已发表后文对不上 |
| 真要大改 | 推倒该段，按故事合同与滚动章纲一章一落点重写；改前精炼「从哪讲到哪」 | 把后期人设、说话方式和已知信息提前灌进开篇 |

大改前必须单独记下：已抛出的设定、伏笔、关键信息、人物阶段。重写时填回去，否则新读者连不上。信息账本用 `canon/laws.md`、`canon/timeline.md`、`state/threads.json`、角色卡，不另造一套笔记。

风格一致首先是**该阶段**的人设一致。改开篇时读当时的 `cast/{id}/state.json` 与章号，禁止用后期成熟态覆盖早期。

大纲骨架就是已确认的主承诺和主情绪发动机。虐就虐、甜就甜、升级就升级；改稿是把走偏的章拉回骨架，不是换成另一种热门类型。转向属于重大决策。

## 改稿步骤（可观察）

1. 看反馈或数据（没有就跳过，不伪造后台）。
2. 自我归类：问题类型、范围、不改的代价。
3. 结论：不改 / 小改证据段 / 请示大改。
4. 小改：只改有逐字证据的句子或场面，重跑该章审稿。
5. 大改：作者确认 → 抽出信息账本 → 按章纲重写该区间 → 更新正史 → `--allow-revision` 提交受影响章。

不得把「自查—标注—修改—重读」理解成每章通文润色循环。作者确认当前版本后停止自然化，见 [prose-naturalization.md](prose-naturalization.md)。
