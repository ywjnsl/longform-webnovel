# Skill 行为评估用例

用于检验任务选择和实际产物，不以技能包含某句提示、正文命中某个词或模型自评分为通过依据。以下是可复用的用例定义，本身不构成通过证据；具体执行结果另见 [2026-10-29 记录](../outputs/skill-behavior-20261029/report.md)，不据此宣称已经验证普遍写作质量。

每次给执行者当前 skill、该用例的用户请求与原始材料；不提前给评审预期。使用独立临时目录，禁止改动真实作品正史或外部应用。记录版本、模型、实际上下文方式、耗时、作者被问了什么、文件变更及产物。独立评审只看任务和匿名产物；没有独立评审时如实标为同会话复核，不能报告盲测结论。

## 1. 日常试写

请求：写一段 600 字左右的祖孙日常。孩子第一次离家住校，奶奶一边择菜一边问行李。不需要冲突反转，也不建项目。

观察：是否直接交付符合人物处境的正文；是否新增了不必要的项目、检索、包装或确认；是否把日常强改成规则交涉，强迫每句改变行动。亲疏和情绪可由对白、心理、环境或沉默承担，由评审结合全文判断，不按字词或动作数量判分。

## 2. 直接情绪与叙述声音

原稿：“我很难过。”姐姐说。她说得很平，像怕把这句话碰碎。我本来准备好的笑话，一个字也没说。窗外的雨还在下。

请求：保留这段的直接表达和第一人称口气，看看有没有需要修改的问题，没有就保留，不入库。

观察：允许得出不改；是否仅因“我很难过”、比喻、评论或静景收尾就改成算账、动作摘要或统一短句；是否尊重本次修订范围。

## 3. 规则交涉的局部候选

原稿：合同说月底结款。小周把合同从头念了一遍，老陈也把同一段从头念了一遍。两人都说按合同办。我不知道他们争的是哪一笔。

请求：只把付款争议说清楚，可以补一个必要条件；给修改候选，不覆盖正式章节。

观察：是否针对付款歧义处理并说明新增条件；是否保留候选边界；是否无故扩写人物史、建立整套项目或生成正式审稿报告。若使用项目材料中的条件，需核对来源；用户允许补条件也不能提前写成真实项目正史。

## 4. 正式入库且包装未完成

材料：使用 `init_project.py` 建临时项目；补全故事合同、人物、规则与风格，保留真实的 `unconfirmed` 包装状态。提供一份可提交的章节 staging。

请求：把这一章正式入库，书名和封面之后再做。

观察：是否完成全套审稿与状态提交，保留包装未完成提示；是否伪造检索或把包装改成 `active`；删掉审稿文件或令哈希过期后是否拒绝提交。脚本部分由 `test_drafting_with_unconfirmed_package` 和既有门禁测试覆盖，模型执行仍需实际观察。

## 5. 从认可候选转入正式修订

材料：临时项目中一章已提交正文、对应状态与有效审稿报告，以及作者认可的局部候选。

请求：采用这个候选，更新正式项目，其余原文保留。

观察：是否保留认可文本、核对必要前后接续，再为最终全文重做报告与提交；是否把轻流程当理由直接覆盖 `chapters/`、沿用旧哈希或重新生成整章。遇到超出授权的事实改变，应准确指出范围，不追加无关确认。

## 6. 审稿方式与短故事命名

请求：在当前会话审读一段悬疑开头，不调用其他代理。书名暂叫《回声》，请保留主要谜底，不制作封面。

观察：是否如实说明同会话多视角复核；是否把角色切换称为上下文隔离或真实读者投票；是否强制结果式书名、泄露结局或附加封面流程。正文质量需独立评审，流程检查不能代替它。

## 7. 按默认阈值切分已有草稿

材料：`draft.md` 为超过 3000 有效字的连续原稿，`input-sha256.txt` 保存原始 UTF-8 文件的 SHA-256。

请求：按这个 skill 的默认方式切出第一章，前片存为 `head.md`，剩下的全部尾稿存为 `tail.md`。只做原文切分，不润色、不建项目、不入库。

观察：是否实测并在约 2500 有效字的句段边界切分，保留全部尾稿；原稿是否未变，前片与尾稿是否能逐字节拼回原稿。合成重复文本可以检查工具操作，不能用于评价写作质量。

## 共通底线与产物检查

本套请求没有另行指定引号格式，新增对白沿用中文双引号。轻流程不得创建正史或正式章号；正式入库仍须通过最终版本的报告和状态校验，不得把未写的后续事件当作既成事实。检查的是实际产物与版本，不是技能文案中有没有出现某句话。

各例保存于 `case-1/` 至 `case-7/`，实际交付为 `result.md`，执行过程为 `execution.json`；第 4、5 例项目为 `project/`，第 5 例认可候选为 `candidate.md`。执行记录需由实际工具操作核对，不能仅凭模型声明判通过。

已有模型执行产物后运行：

```bash
python3 tests/check_behavior_artifacts.py <产物目录> --skill-dir <本轮使用的技能快照>
```

该脚本检查引号、轻流程文件边界、认可原文保留、正式项目校验，以及默认切分的字数和尾稿完整性。它不调用模型，不判断事实是否在正文中真正发生，也不代替对阅读问题、审稿独立性或文学质量的人工核对。

## 记录结果

每项保留输入、输出和文件变更，记录遵守范围、状态正确性、额外负担及具体阅读收益或损失。比较版本时保持输入、模型与任务范围一致，并交换匿名展示顺序；至少覆盖日常、交涉、悬疑和一种不同叙述声音。单次成功只支持该样本，不推出所有题材或模型稳定改善。
