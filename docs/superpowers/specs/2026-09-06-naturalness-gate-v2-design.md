# 中文网文自然度门禁 v2 设计

## 背景

现有 skill 已提供自然化指导、章节自然度审稿和 `prose_lint.py`，但确定性检查仍有空档：长短语必须重复至少三次才会报告，整句在不同位置原样出现两次可能漏检；`chapter_metrics.py` 只识别完全相同的整段；作者声音基线主要比较平均句长、段长和对白比例；外部检测反馈尚无结构化记录方式。

本次改造把自然度定义为人物声音、场景具体性、信息留白、节奏变化和无意重复的综合质量，不把检测器分数当作作者身份判断或唯一优化目标。

## 目标

1. 对全文精确重复句和高相似近似复述建立可靠门禁，覆盖此前“两次重复但未报告”的缺陷。
2. 把无功能副词、工整金句、对仗回环、模板句法、整齐段落包和人物同声转化为有证据的审稿信号。
3. 用作者确认稿建立项目声音基线，避免按通用“人类写作模板”改稿。
4. 接收朱雀逐段标红或报告截图，并把它作为可追踪的外部诊断证据。
5. 所有自动修订保持局部、可复审，并继续绑定最终正文 SHA-256。

## 非目标

- 不承诺通过或规避朱雀及其他 AI 检测器。
- 不通过错别字、病句、随机断句、无功能口语、硬塞闲笔或刻意增加噪声降分。
- 不无差别删除所有副词，不把单个词命中视为缺陷。
- 不引入联网检测服务或强制第三方 Python 依赖。
- 不允许根据检测分数循环整篇重写。

## 方案

### 1. 确定性重复审计

新增 `scripts/repetition_audit.py`，在单章和整部作品两个范围运行。脚本复用现有 Markdown 清洗与中文字符计数逻辑，输出句子或段落在正文中的文件、段落号、句号和逐字证据。

检查分三级：

- `exact-sentence-duplicate`：规范化标点和空白后，内容不少于 14 个字符的句子出现两次即报告；未解决时阻断提交。
- `near-sentence-duplicate`：内容不少于 18 个字符的句子按中文字符 3-gram 计算 Jaccard；高相似候选成对报告，默认阈值 0.82。它是强复核项，只有编辑确认属于无意复述时才阻断。
- `repeated-conclusion`：相邻或近邻段落以不同措辞重复同一判断，由自然度语义审稿定位；不得用字符串分数冒充语义判断。

标题、章节编号、极短对白不进入比较。刻意回环、证词复述、角色口头禅和必要规则复述可写入章节审稿中的 `repetitionExceptions`；例外必须包含成对位置、用途、最终正文哈希，不能做全局模糊白名单。

一万二千字短故事规模允许直接比较候选句对，无需 MinHash/LSH 依赖。实现保留稳定的字符 shingles 接口，未来处理百万字项目时再考虑索引优化。

### 2. 副词与模板节奏审计

扩展 `scripts/prose_lint.py`，新增 `modifier-cluster`、`rhetorical-symmetry` 和 `cadence-packaging` 风险信号。

副词不按词表逐个删除。扫描器只在以下条件之一成立时报告：同一弱副词在局部窗口反复出现；多个通用程度、判断或动作副词连续替代具体动作；频率明显偏离作者确认基线。初始复核词包括“其实、显然、忽然、突然、缓缓、轻轻、微微、默默、下意识地、终于、只是、竟然”等，但单次出现不计缺陷。

审稿时先判断副词是否改变动作速度、视角判断、信息可靠性或人物语气。有功能则保留；无功能时优先删除，或将必要信息落实为动作、距离、物件反应和选择后果。不得为减少副词把全文改成同长度短句。

`rhetorical-symmetry` 检查成组的工整金句、对仗回环、二元短句和可摘抄式结论，例如反复出现的“X 在，Y 在”“两张纸。两个签名。”式骨架。单个成立且符合人物声音的句子可以保留；同一场景连续用工整结构替人物和读者总结时，优先删除结论或改成由具体处境决定的不对称句法。

`cadence-packaging` 检查成组的“短动作 - 精准反驳 - 旁白总结”、机械长短交替、连续相同句首和段尾判词。统计结果只负责指出候选位置，最终缺陷由上下文审稿确认。句长方差是观察值，不是优化目标；禁止为了提高方差机械增加三字段、逗号长句或独句成段。

### 3. 场景自然化手段

把可用手段分成“由场景条件触发的写法”而不是固定配方：

- **数字与主观估算并置**：账目、日期、路程或次数确实影响人物选择时，可让精确事实与人物不可靠的估算、记忆或夸张同时存在。数字必须来自正史或当前场景，不得为制造真人感凭空编造；主观偏差必须符合视角人物并可能影响判断。
- **对白落到短反应**：对白改变权力、理解或行动时，可用极短反应句承接，让话产生可见后果。禁止每轮对白都套用这一节拍，否则它本身会成为模板。
- **碎化对白与误解往返**：人物信息不对称、回避核心或关系紧张时，允许追问、打断、答非所问、改口、重复和迟疑。不得把完整条款机械切碎，或给每个角色添加相同的结巴、破折号和省略号。
- **主观不确定与自我打断**：视角人物可以暂时放下疑点、记不清、误判或不愿细想。未知必须与正史事实口径一致，并在后续改变选择、代价或信息边界；不能只用“算了”藏起作者尚未解决的因果漏洞。
- **动作锚代替情绪标签**：当动作、距离、物件或身体后果已经传达尴尬、愤怒或犹豫时，删除紧随其后的情绪解释。动作必须属于人物和场景，不能换成另一组万能微表情。
- **弱情节闲笔**：允许与主线因果关系较弱、但承担视角偏好、关系温度、生活秩序、空间连续性或节奏缓冲的细节。完全不改变注意力、人物、环境理解或阅读节奏的素材不保留；禁止以“提高困惑度”为理由批量添加废墨。

这些手段可以组合，但每个场景只选择当下真正需要的部分。精确数字、短反应、误解、闲笔和自我打断如果跨场景高频复现，同样进入模板复核。

### 4. 作者与角色声音基线

继续使用 `canon/style-profile.md`，只接收作者确认满意的正文、作者原创样稿或人工“改前 - 改后”配对样本。新增可计算但不裁决的分布信息：句长分位数、段长分位数、对白比例、问句比例、称呼方式、连接词、副词和标点分布。

角色声音比较只在样本量足够时启用。它比较角色的当下利益、回避方式、问答习惯和称呼变化，不用给不同人物机械分配长句、短句或口头禅。人物相似度只能触发复核，不能自动改写对白。

### 5. 朱雀外部反馈

在章节审稿 JSON 中增加可选 `externalNaturalness` 对象：

```json
{
  "provider": "zhuque",
  "checkedAt": "ISO-8601 时间",
  "reviewedTextSha256": "被检测正文哈希",
  "overallSignal": "用户提供的原始结果，不转换成人类概率",
  "sourceArtifacts": ["reviews/evidence/朱雀-第0001章.png"],
  "flaggedPassages": [
    {
      "text": "正文中的逐字片段",
      "location": {"paragraph": 12},
      "externalLabel": "截图中的原始标记",
      "editorDiagnosis": "over-explanation",
      "action": "revised",
      "resolved": true
    }
  ]
}
```

截图由审稿者读取后人工转录标红片段；转录文本必须能在对应哈希的正文中逐字找到。只有百分比而没有逐段证据时，记录 `overallSignal`，不自动生成修改任务。朱雀标红必须映射到现有或新增的编辑类别，并说明读者代价；无法说明文本问题的标红保留为外部备注，不触发重写。

### 6. 审稿流程与门禁

正文写成或修改后按以下顺序执行：

1. 运行章节指标、`prose_lint.py` 和 `repetition_audit.py`。
2. 审稿者在不先读扫描结论的情况下顺读正文，记录自然度问题簇。
3. 用扫描结果复核遗漏，并导入可用的朱雀逐段证据。
4. 对有逐字证据的问题做一次局部修订；禁止整章或整篇重新生成。
5. 基于最终正文重新运行全部扫描、自然度审稿、编辑审稿和读者模拟。

未解决的精确重复句、确认成立的高相似复述、`needs-revision` 或 `high` finding 阻断提交。副词密度、风格漂移和外部检测分数本身不阻断提交。所有报告继续绑定最终正文 SHA-256，正文一旦变化即失效。

## 数据与错误处理

- JSON 输出包含 `schemaVersion`、正文哈希、扫描范围、findings 和例外。
- 每个重复 finding 至少包含两个位置和两段原文；位置解析失败时报告错误，不静默通过。
- 找不到朱雀截图、截图与当前正文不匹配或转录片段不在正文时，外部反馈标记为无效，不影响确定性门禁继续运行。
- 空文本、不可读文件和错误编码沿用现有脚本的非零退出约定。

## 测试策略

严格执行 RED-GREEN-REFACTOR：

1. 先加入包含同一长句两次的回归测试，确认当前实现无法拦截。
2. 分别测试标点/空白变化、近似改写、短常用对白、刻意回环例外和跨章节重复。
3. 测试单个副词不报告、局部副词簇报告、成组对仗金句报告、单个合理金句不报告，以及作者基线明显偏移报告。
4. 用场景测试验证数字与主观估算、短反应、碎化对白和弱情节闲笔只在有视角或关系功能时使用，不退化成固定配方。
5. 测试朱雀逐字片段与正文哈希校验、截图缺失和无逐段证据只有总分的情况。
6. 运行自然度门禁专项测试、项目全量测试和 skill 快速验证。

回归语料同时包含应拦截样本和合法反例，避免为抓住一个重复句而误伤人物口癖、悬疑复沓、法庭质询和题材必要流程。
